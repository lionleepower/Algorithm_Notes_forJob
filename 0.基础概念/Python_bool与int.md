# Python bool 与 int：布尔本来就是整数

Python 里 `bool` 是 `int` 的**子类**，`True` 和 `False` 就是 `1` 和 `0`，只是打印时换了个名字。算法题中这让「条件」可以直接参与算术——计数不必写 `if`，DP 的代价指示器可以写成一个括号。

---

## 思路

很多人卡在这里：「比较运算符 `x == y` 返回的不应该是 `True` / `False` 吗？为什么有时候又变成 `1` / `0`？」

**它从来没变过。** 比较运算符**永远**返回布尔值，变的是**谁在消费这个值**。理解这一点，`dfs(...) + (s[i] != t[j])` 这类写法就不再是「技巧」，而是自然结果。

> [!tip]- 核心思路
> 
> ```python
> isinstance(True, int)      # True  ← 关键事实：bool 继承自 int
> True + True                # 2
> 5 + False                  # 5
> sum([True, False, True])   # 2
> ```
> 
> `+` 只认识数字，它调用 `int.__add__`，于是 `True` 就以本来面目（`1`）参与运算。**这不是「类型转换」，而是布尔本来就是整数的一种。**

---

## 1. 同一个值，三种上下文

`True` 不是「另一个世界的类型」，它只是在不同上下文里换了张脸：

| 上下文 | 表现 | 说明 |
| --- | --- | --- |
| `print(x == y)` | 显示 `True` | 走 `__repr__`，显示成人类可读的名字 |
| `if x == y:` | 当真假用 | 布尔上下文 |
| `a + (x == y)` | 当 `1` / `0` 用 | **算术上下文** |

> [!example]- 亲眼看一遍
> 
> ```python
> flag = (3 > 2)
> 
> print(flag)          # True      ← 打印时是名字
> print(flag + 10)     # 11        ← 算术时是 1
> print(flag * 5)      # 5
> print([10, 20][flag])# 20        ← 连索引都能用，flag 就是下标 1
> ```
> 
> 最后一行值得记：布尔能直接当**下标**，因为它就是 `0` / `1`。

---

## 2. 实例一：计数不必写 if

既然布尔能当 `1` / `0`，「统计满足条件的个数」就是「把布尔加起来」：

> [!success]- 常用计数写法
> 
> ```python
> cnt  = sum(c == 'a' for c in s)                # 统计字符出现次数
> diff = sum(a != b for a, b in zip(s, t))       # 汉明距离：对应位不同的个数
> odd  = sum(x % 2 for x in nums)                # 奇数个数
> pos  = sum(x > 0 for x in nums)                # 正数个数
> ```
> 
> 对照笨写法，短且不易错：
> 
> ```python
> # 啰嗦版
> cnt = 0
> for c in s:
>     if c == 'a':
>         cnt += 1
> 
> # 中间版：多建了一个列表，白占 O(n) 空间
> cnt = len([c for c in s if c == 'a'])
> ```
> 
> `sum(生成器)` 是**惰性**的，全程 $O(1)$ 额外空间；列表推导会先把整个列表建出来，$O(n)$ 空间。面试里这类写法既短又能体现对生成器的理解。

## 3. 实例二：DP 里当「代价指示器」

来源是 [[7.3 线性dp 最长公共子序列]] 的编辑距离统一写法：

> [!success]- 编辑距离的一行合并
> 
> ```python
> return min(dfs(i-1, j)   + 1,                    # 删除
>            dfs(i, j-1)   + 1,                    # 插入
>            dfs(i-1, j-1) + (s[i] != t[j]))       # 替换：相等免费，不等付 1
> ```
> 
> 末尾那个 `(s[i] != t[j])` 就是「这一列要不要付替换费」的**指示器**——相等返回 `False`（`0`，免费），不等返回 `True`（`1`，付一次操作）。
> 
> 不用这招就得拆成两支：
> 
> ```python
> if s[i] == t[j]:
>     cost = 0
> else:
>     cost = 1
> return min(..., dfs(i-1, j-1) + cost)
> ```
> 
> LCS 里同理，`dfs(i-1, j-1) + (s[i] == t[j])` 表示「配上了就 +1，没配上 +0」。

## 4. 跨语言：这招能不能用

| 语言 | 机制 | 能否直接相加 |
| --- | --- | --- |
| **Python** | `bool` **是** `int` 的子类 | 能，`a + (x == y)` |
| **C++** | `bool` 在算术表达式里发生**整型提升** | 能，`a + (x == y)` |
| **Java / Go** | `bool` 与 `int` 完全隔离 | **不能**，必须显式转换 |

> [!warning]- Java / Go 里必须显式写
> 
> ```java
> // Java：三元表达式显式转换
> return dfs(i-1, j-1) + (s.charAt(i) != t.charAt(j) ? 1 : 0);
> ```
> 
> ```go
> // Go：连三元都没有，只能写 if
> cost := 0
> if s[i] != t[j] {
>     cost = 1
> }
> ```
> 
> Python 是「布尔本来就是整数」，C++ 是「布尔会被隐式转成整数」——路径不同但用起来一样。**这只是 Python / C++ 的便利，不是通用真理**，换语言写题时别想当然。

## 5. 常见易错点

> [!warning]- 易错点
> 
> - **用 `is` 判断相等**：`True is 1` 是 `False`！`is` 比的是**对象身份**，`True` 和 `1` 是两个不同对象，只是数值相等。判断相等永远用 `x == y`，`is` 只留给 `is None`（详见 [[Python_赋值与拷贝]]）。
> - **`isinstance(x, int)` 会把布尔放进来**：因为 `bool` 是 `int` 的子类，`isinstance(True, int)` 返回 `True`。真要排除布尔得写 `type(x) is int`，或显式 `not isinstance(x, bool)`。
> 
>   ```python
>   def only_int(x):
>       if isinstance(x, int):     # True / False 也会通过！
>           ...
>   ```
> 
> - **字典 key 会撞车**：`True` 和 `1` 的哈希相同且相等，所以它们是**同一个 key**。
> 
>   ```python
>   d = {1: 'one', True: 'true'}
>   print(d)        # {1: 'true'}  ← 只剩一个键值对
>   print(len(d))   # 1
>   ```
> 
>   同理 `{0: ..., False: ...}` 也会合并。用布尔和整数混作 key 时务必小心。
> - **排序时 `False` 排在 `True` 前面**：因为 `0 < 1`。`sorted([True, False])` 得到 `[False, True]`，这通常是想要的，但别以为它有特殊规则。
> - **为了炫技牺牲可读性**：`a + (x == y)` 在 DP 代价、计数场景里是惯用法；但如果表达式复杂到看不出布尔在哪，老实写 `if` 更好。

---

## 复杂度

> [!summary]- 复杂度
> 
> - `sum(条件 for x in data)`：时间 $O(n)$，额外空间 $O(1)$——生成器惰性求值，不建中间列表。
> - `len([x for x in data if 条件])`：时间同为 $O(n)$，但额外空间 $O(k)$（`k` 为满足条件的元素数）。
> - 布尔参与算术本身是 $O(1)$，没有任何转换开销——它本来就是整数。

---

## 一句话总结

比较运算符**永远**返回布尔，变的只是谁在消费它——`print` 时显示名字、`if` 里当真假、算术里当 `1` / `0`；因为在 Python 里 `bool` 根本就是 `int` 的子类。

## 模板归纳

看到以下信号，优先想到「布尔当整数」：

- **统计满足条件的个数** → `sum(条件 for x in data)`，别写 `if` 累加
- **两个状态的代价是 0 或 1** → 直接把比较式加进去，别拆 `if / else`
- **要按条件二选一取值** → `[取假时的值, 取真时的值][条件]`（可读性一般，慎用）

```python
# 计数
cnt = sum(c == target for c in s)

# 0 / 1 代价指示器（DP 常用）
total = sub_result + (a != b)          # 不等付 1，相等免费

# 判断相等永远用 x == y，不要用 is（除了 is None）
```
