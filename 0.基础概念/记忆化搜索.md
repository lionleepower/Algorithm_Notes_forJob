# 记忆化搜索：给纯函数递归加一层缓存

记忆化搜索 (Memoization) = 朴素递归 + 一张「算过就记下」的缓存表。它把动态规划里被反复重算的重叠子问题各只算一次，在**几乎不改递归结构**的前提下，把指数级复杂度塌缩成多项式。

---

## 思路

它是「自顶向下」写 DP 最省脑的方式：递归方程照写，只在函数体头尾各加一句「先查表 / 算完存表」。前提是这个递归函数**无后效性**——返回值只由参数决定，缓存才合法（判据见 [[重叠子问题与无后效性]]）。

> [!tip]- 核心思路
> 
> 三步套在任何递归上：
> 
> ```python
> def dfs(i):
>     if i < 0:              # ① base case 永远排最前
>         return 0
>     if memo[i] != -1:      # ② 查表：算过直接返回
>         return memo[i]
>     memo[i] = ...递归...   # ③ 算完存表再返回
>     return memo[i]
> ```
> 
> 它和「先生成再剪枝」无关——记忆化不砍分支，而是**让重复分支的第二次访问变成 $O(1)$ 查表**（与 [[剪枝]] 的「进门前砍子树」是两码事）。

---

## 1. 记忆化 vs 剪枝：别混

原稿把记忆化口头叫作「剪枝」，机制其实不同，面试里要说清：

> [!success]- 两者对照
> 
> | | [[剪枝]] | 记忆化 |
> | --- | --- | --- |
> | 时机 | 进入递归**之前** | 递归**返回值算出后** |
> | 做什么 | 判定子树注定失败，整棵不进 | 存下已算结果，重复访问直接取 |
> | 成立前提 | 存在「不可逆量」 | 无后效性（纯函数） |
> | 效果 | 少走注定无解的分支 | 重叠子问题只算一次 |

---

## 2. base case 必须排在查表之前

顺序反了会静默出错，且极难查。

> [!warning]- Python 负下标陷阱
> 
> ```python
> def dfs(i):
>     if memo[i] != -1:      # ← 危险：写在 base case 前
>         return memo[i]
>     if i < 0:
>         return 0
> ```
> 
> Python 里 `memo[-1]` **不报错**，会安静返回列表最后一项。于是 `dfs(-1)` 可能返回一笔真实结果而非 base case 的 0，答案错、不抛异常。原则：**base case 是合同的边界定义，永远最前；查表是性能优化，排在合法性检查之后**——优化不该影响正确性。

---

## 3. 哨兵值 `-1` 是有前提的

`-1` 表示「尚未计算」，成立的唯一理由是**真实答案永远不可能是 -1**。

> [!warning]- 什么时候不能用 -1
> 
> - 答案可能为负的题（带惩罚的路径 DP）：`-1` 会把合法结果误判成「没算过」，退化回指数级，甚至逻辑对但反复重算。
> - 稳妥替代：用 `None` 作哨兵，或另开一个布尔 `visited` 数组，把「算没算过」和「结果值」彻底分开。
> - 数组哨兵还要求参数是小范围非负整数；参数是字符串 / 元组 / 可能为负时，直接用 `dict`（或 [[Python_cache|@cache]]）。

---

## 4. 手写 memo 与 `@cache` 的取舍

`functools.cache` 帮你做的事和手写**逐字对应**（机制详见 [[Python_cache]]）：建 dict、按参数查、算完写回。

> [!summary]- 什么时候手写、什么时候 @cache
> 
> - `@cache`：面试速写首选，多维参数零改动，dict 自带「在不在」标记、不需要哨兵。
> - 手写数组：小范围整数参数下 $O(1)$ 随机访问、常数更小；C++ 没有装饰器时必须手写。
> - 复杂度通用公式：$\text{时间} = \text{状态个数} \times \text{单次转移时间}$。打家劫舍状态数 $n$、转移 $O(1)$ ⇒ $O(n)$。

---

## 一句话总结

记忆化搜索 = 无后效性递归 + 缓存表，改动最小地把重叠子问题从指数塌缩到线性；写的时候只记两条铁律：base case 在查表前、哨兵值必须是不可能的真实答案。

---

## 模板归纳

看到「递归方程已写出，但同一参数被反复重算」，就加记忆化：

- 参数是小范围非负整数 → 数组 memo + 哨兵 `-1`（答案可能为负改 `None` / `visited`）。
- 参数多维 / 非整数 / 图搜索 → `@cache` 或手写 `dict`。
- 顺序永远是：base case → 查表 → 算 → 存表。

```python
from functools import cache

@cache
def dfs(i):
    if i < 0:                 # base case
        return 0
    return max(dfs(i - 1), dfs(i - 2) + a[i])   # 转移方程
```
