# 相向双指针：多数之和

## 解决什么问题

注意：双向指针的前提就是有序
**有序**数组上，左右两个指针从两端向中间收缩，每一步都能**排除一整批候选**。识别信号：

```text
数组有序（或允许排序）+ 找满足某个和 / 面积条件的一对或若干个元素 + 要去重
```

`2Sum` 是模板本身，`3Sum` / `4Sum` 只是「先固定几个数，把剩下的化归成 2Sum」。

## 核心：为什么能一次排除一整行

![](assets/1.0%20相向双指针%20排除法.svg)

> [!tip]- 排除法：这才是 $O(n)$ 的来源
> 
> 把候选组合看成一张 $n \times n$ 的表，格子 $(left,\ right)$ 表示一个候选对。暴力要看 $n^2/2$ 个格子，而双指针每走一步就**整行或整列**地划掉：
> 
> - `s > target` ⇒ 对任意 $l' > l$ 都有 `a[l'] + a[r] >= a[l] + a[r] > target`，**这一列全体出局** ⇒ `right -= 1`
> - `s < target` ⇒ 对任意 $r' < r$ 都有 `a[l] + a[r'] <= a[l] + a[r] < target`，**这一行全体出局** ⇒ `left += 1`
> 
> 两个指针各自最多走 $n$ 步且**永不回头**，所以是 $O(n)$。
> 
> **前提是数组有序**——这就是排序的第一个作用。无序时 `left += 1` 不保证和变大、`right -= 1` 不保证和变小，上面两条论证同时失效。
> 
> 排序的第二个作用是**让重复元素相邻**，去重才有办法写（见下）。

## 变体一：167. 两数之和 II（模板本身）

输入是**已排序**数组，找和为 `target` 的两个数，返回 `1-based` 下标。

> [!success]- Python 实现
> 
> ```python
> class Solution(object):
>     def twoSum(self, numbers, target):
>         left = 0
>         right = len(numbers) - 1
>
>         while left < right:
>             s = numbers[left] + numbers[right]
>
>             if s == target:
>                 return [left + 1, right + 1]   # 题目要求 1-based
>             elif s < target:
>                 left += 1                      # 和太小 → 抬高左边
>             else:
>                 right -= 1                     # 和太大 → 压低右边
> ```
> 
> - **主流程**：`s` 与 `target` 比大小，只有三种走向，每一步排除一行或一列。
> - **易错位置**：返回值要 `+1`；循环条件是 `left < right` 而不是 `<=`（同一个元素不能用两次）。
> - 题目保证恰好有一个解，所以循环外不用写兜底 `return`；若不保证，应在末尾补一个 `return []`。

> [!example]- 示例推演
> 
> ```python
> numbers = [2, 7, 11, 15]，target = 9
> ```
> 
> ```text
> left=0, right=3   2 + 15 = 17 > 9   → right 左移（第 3 列全体出局）
> left=0, right=2   2 + 11 = 13 > 9   → right 左移
> left=0, right=1   2 +  7 =  9       → 找到，返回 [1, 2]
> ```

## 变体二：15. 三数之和（固定一个数 + 2Sum）

找出所有和为 `0` 且**不重复**的三元组。

> [!tip]- 核心思路：归约 + 三层去重
> 
> **归约**：原问题 $a + b + c = 0$，固定 $a = nums[i]$ 后就变成在右侧区间里找 $b + c = -a$——**一个标准的 2Sum**。
> 
> ```text
> 排序 → 固定 nums[i] → 在右侧区间做 Two Sum → 去重
> ```
> 
> **去重必须做三层**，少一层就会出重复答案：
> 
> | 层 | 写法 | 作用 |
> | --- | --- | --- |
> | 固定值 | `if i > 0 and x == nums[i-1]: continue` | 同一个 `a` 只处理一次 |
> | 左指针 | 找到答案后 `while nums[left] == nums[left-1]: left += 1` | 跳过相同的 `b` |
> | 右指针 | 找到答案后 `while nums[right] == nums[right+1]: right -= 1` | 跳过相同的 `c` |
> 
> **两个剪枝，`break` 与 `continue` 不能互换**：
> 
> - `x + nums[i+1] + nums[i+2] > 0` → **`break`**：当前 `x` 配上最小的两个数都已经超了，而后面的 `x` 只会**更大**，整个循环可以直接结束。
> - `x + nums[n-2] + nums[n-1] < 0` → **`continue`**：当前 `x` 配上最大的两个数还不够，说明**只是这个 `x` 太小**，换个更大的 `x` 仍可能有答案，只能跳过这一轮。

> [!success]- Python 实现
> 
> ```python
> class Solution(object):
>     def threeSum(self, nums):
>         nums.sort()                                   # 提供单调性 + 让重复元素相邻
>         ans = []
>         n = len(nums)
>
>         for i in range(n - 2):
>             x = nums[i]
>             if i > 0 and x == nums[i - 1]:            # 去重①：固定值
>                 continue
>             if x + nums[i + 1] + nums[i + 2] > 0:     # 剪枝①：往后只会更大
>                 break
>             if x + nums[n - 2] + nums[n - 1] < 0:     # 剪枝②：只是这个 x 太小
>                 continue
>
>             left, right = i + 1, n - 1
>             while left < right:
>                 s = x + nums[left] + nums[right]
>                 if s == 0:
>                     ans.append([x, nums[left], nums[right]])
>                     left += 1
>                     while left < right and nums[left] == nums[left - 1]:
>                         left += 1                     # 去重②：左指针
>                     right -= 1
>                     while left < right and nums[right] == nums[right + 1]:
>                         right -= 1                    # 去重③：右指针
>                 elif s < 0:
>                     left += 1
>                 else:
>                     right -= 1
>         return ans
> ```
> 
> - **代码结构**：外层 `for` 固定第一个数，内层 `while` 就是变体一的模板。
> - **易错位置**：找到答案后**左右指针都要移动**——只动一个必然原地重复命中同一组解。

> [!example]- 示例推演
> 
> ```python
> nums = [-1, 0, 1, 2, -1, -4]   →   排序后 [-4, -1, -1, 0, 1, 2]
> ```
> 
> ```text
> 固定 -4：右侧双指针找不到答案
> 固定 -1：-1 + -1 + 2 = 0  →  [-1, -1, 2]
>          -1 +  0 + 1 = 0  →  [-1,  0, 1]
> 固定第二个 -1：与前一个固定值重复，跳过     ← 去重①
>
> 答案 [[-1, -1, 2], [-1, 0, 1]]
> ```

## 易错点

> [!warning]- 易错点
> 
> - **没排序就用相向双指针**：模板依赖单调性。无序时 `left += 1` 不一定让和变大、`right -= 1` 不一定让和变小，排除法直接失效。
> - **167 忘记返回 1-based 下标**：要 `return [left + 1, right + 1]`。
> - **3Sum 只对固定值去重**：三层去重缺一不可，只去重 `nums[i]` 仍会产生重复三元组。
> - **找到答案后只移动一个指针**：必须 `left += 1` 且 `right -= 1`，再各自跳过重复值；只动一个会重复命中。
> - **剪枝的 `break` / `continue` 混淆**：「最小三数和已经大于 0」用 `break`（后面只会更大）；「最大三数和仍小于 0」用 `continue`（换个更大的 `x` 还有希望）。写反了要么漏解、要么白跑。
> - **循环条件写成 `left <= right`**：会把同一个元素用两次。

## 复杂度

> [!summary]- 复杂度
> 
> **167. 两数之和 II**
> 
> - 时间 $O(n)$ —— 两个指针合计最多移动 $n$ 次且永不回头。
> - 空间 $O(1)$ —— 只用常数个变量。
> 
> **15. 三数之和**
> 
> - 时间 $O(n^2)$ —— 排序 $O(n\log n)$ + 外层固定一个数 $O(n)$ × 内层双指针 $O(n)$，主导项是 $O(n^2)$。
> - 空间 $O(1)$（不计返回结果）—— 排序若用原地实现则不额外占用；返回的三元组列表另计。
> - 推广：`kSum` 是 $O(n^{k-1})$——每多固定一个数，就多一层 $O(n)$ 的循环。

## 一句话总结

排序换来单调性，单调性换来**每一步排除一整行或一整列**的资格——这就是相向双指针把 $O(n^2)$ 压成 $O(n)$ 的全部原理；`kSum` 则是「固定到只剩两个数」的归约游戏。

## 模板归纳

看到「**多数之和 + 允许排序 + 要去重**」，三步落笔：

1. **先排序**——它同时提供两样东西：指针移动的方向感，以及让重复元素相邻（去重的前提）。
2. **归约到 2Sum**：`3Sum` = 固定 1 个数 + 2Sum；`4Sum` = 固定 2 个数 + 2Sum；`kSum` = 固定 1 个 + `(k-1)Sum`。
3. **写内层双指针**：太小移左、太大移右；命中后**两个指针一起动**，并各自跳过重复值。

```python
# 相向双指针通用骨架
nums.sort()
left, right = 0, len(nums) - 1
while left < right:
    s = nums[left] + nums[right]
    if s == target:
        record()
        left += 1;  right -= 1
        while left < right and nums[left]  == nums[left - 1]:  left += 1     # 去重
        while left < right and nums[right] == nums[right + 1]: right -= 1
    elif s < target:
        left += 1          # 和太小 → 排除掉这一整行
    else:
        right -= 1         # 和太大 → 排除掉这一整列
```
