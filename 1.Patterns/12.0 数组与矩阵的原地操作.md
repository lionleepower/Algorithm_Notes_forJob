# 数组与矩阵的原地操作

## 解决什么问题

LeetCode「普通数组 / 矩阵」这一格里几乎没有新算法，题目难度全部压在同一句话上：

> **不许开额外数组，把元素搬到它该去的位置。**

朴素解法都是「新开一个数组抄过去」，$O(mn)$ 空间秒过；面试真正要问的是**怎么把空间压到 $O(1)$**。压缩的手法只有三种，Hot100 的五道题正好一种一到两道：

| 手法 | 做法 | 代表题 |
| --- | --- | --- |
| **对称反转**：把「整体位移」拆成若干次翻转 | 每次交换换回两个格子，天然原地 | 189 轮转数组、48 旋转图像 |
| **借位标记**：拿数据结构自己的一部分当标记数组 | 需要额外一个变量处理「借位处的冲突」 | 73 矩阵置零、41 缺失的第一个正数 |
| **游标围出未处理区域**：几个下标描述「还没走过的矩形」 | 每步让区域**严格变小**，保证终止 | 54 螺旋矩阵、240 搜索二维矩阵 II |

三种手法的共同点：**信息不能凭空消失，只能换个地方存**。反转是把信息换个顺序存，借位是把信息挤进原数据里，游标是把信息压缩进几个整数。

## 典型变体

### 变体一：189. 轮转数组（对称反转）

把数组向右轮转 `k` 位，要求原地、$O(1)$ 空间。

关键在于先把题意翻译成一句话：数组是 `A | B` 两段，轮转就是要变成 `B | A`。三次反转恰好实现这个恒等式。

![](assets/12.0%20三次反转.svg)

> [!tip]- 核心思路：reverse( reverse(A) · reverse(B) ) $=$ B · A
> 
> 记前 $n-k$ 个为 `A`、后 $k$ 个为 `B`，目标是 `B A`。
> 
> 1. 整体反转 $\Rightarrow$ `reverse(B) reverse(A)`——**两块的位置已经对了**，只是各自内部倒着。
> 2. 反转前 $k$ 个（即 `reverse(B)`）$\Rightarrow$ `B reverse(A)`。
> 3. 反转后 $n-k$ 个（即 `reverse(A)`）$\Rightarrow$ `B A`。
> 
> 每次反转都是相向双指针一路交换，与 [[4.0 反转链表]] 的区间反转是同一个动作，只是数组能随机访问，不必倒指针。

> [!success]- 代码实现
> 
> ```python
> class Solution:
>     def rotate(self, nums: List[int], k: int) -> None:
>         n = len(nums)
>         k %= n                              # k 可能大于 n
> 
>         def reverse(i: int, j: int) -> None:
>             while i < j:
>                 nums[i], nums[j] = nums[j], nums[i]
>                 i += 1
>                 j -= 1
> 
>         reverse(0, n - 1)
>         reverse(0, k - 1)
>         reverse(k, n - 1)
> ```
> 
> - 主流程：取模 → 整体反 → 前 `k` 反 → 后 `n-k` 反。
> - 关键变量：只有 `i`、`j` 两个下标，无额外容器。
> - 易错位置：漏掉 `k %= n`；以及**必须原地改**——写 `nums = nums[-k:] + nums[:-k]` 只是把局部名字重新绑定到新列表，调用方看到的还是旧数组。要原地覆盖得写切片赋值 `nums[:] = ...`（见 [[Python_赋值与拷贝]]），但那样空间是 $O(n)$，不满足进阶要求。

> [!example]- 备选解法：环状替换
> 
> 从下标 0 出发，把 `nums[i]` 送到 `nums[(i + k) % n]`，被顶掉的元素继续往下送，绕回起点算走完一圈。
> 
> 一圈不一定覆盖所有元素——圈数恰好是 $\gcd(n, k)$，所以要从 `0, 1, 2, ...` 各起一次，用「已移动个数等于 $n$」作总出口。
> 
> 时间同样 $O(n)$，但边界比三次反转难写得多。**面试首选三次反转**，环状替换留作「还有别的做法吗」的口述备选。

### 变体二：48. 旋转图像（对称反转）

`n × n` 矩阵原地顺时针旋转 90°。

![](assets/12.0%20旋转等于转置加翻列.svg)

> [!tip]- 核心思路：一次旋转 = 两次对称
> 
> 坐标目标是 $(i, j) \to (j,\ n-1-i)$。直接按这个公式搬会形成四元环，写起来容易乱；拆成两次对称，每一步都退化成「两两交换」：
> 
> - **转置**（沿主对角线翻）：$(i, j) \to (j, i)$
> - **每行左右翻转**：$(j, i) \to (j,\ n-1-i)$
> 
> 复合起来正是顺时针 90°。顺序不能交换：**先翻列再转置得到的是逆时针**。逆时针的正确写法同理——转置 + 每列上下翻转。

> [!success]- 代码实现
> 
> ```python
> class Solution:
>     def rotate(self, matrix: List[List[int]]) -> None:
>         n = len(matrix)
>         for i in range(n):
>             for j in range(i + 1, n):        # 只走上三角，关键！
>                 matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
>         for row in matrix:
>             row.reverse()
> ```
> 
> - 易错位置：内层写成 `range(n)` 会把每一对 $(i,j)$ 与 $(j,i)$ 交换两次，等于什么都没做——本题第一高频错误。必须 `range(i + 1, n)`，见 [[Python_range]]。
> - 若追问「能不能一趟做完」：取四元组 $(i,j) \to (j, n-1-i) \to (n-1-i, n-1-j) \to (n-1-j, i)$ 一轮四赋值，外层只遍历左上角 $\lfloor n/2 \rfloor \times \lceil n/2 \rceil$ 个格子。

### 变体三：73. 矩阵置零（借位标记）

某个元素为 0 就把它所在的整行整列都置零，要求 $O(1)$ 额外空间。

朴素做法开两个数组 `row[m]`、`col[n]` 记标记，$O(m+n)$ 空间。既然要降到 $O(1)$，就得**把这两个标记数组塞回矩阵自己身上**——第 0 行天生有 `n` 格，第 0 列天生有 `m` 格，正好够用。

![](assets/12.0%20首行首列当标记位.svg)

> [!tip]- 核心思路：借位一定会撞车，撞车处用一个普通变量兜底
> 
> 约定 `matrix[i][0]` 为 0 表示「第 `i` 行要清零」，`matrix[0][j]` 为 0 表示「第 `j` 列要清零」。问题在于 **`matrix[0][0]` 被两个约定同时征用**，一个格子存不下两个 bit。
> 
> 解法：先用布尔变量 `col0` 把「第 0 列到底要不要清零」这条信息单独存走，此后 `matrix[i][0]` 只承担行标记这一个职责。
> 
> 第二个坑是**写回顺序**。从上往下写，一旦第 0 行被清成 0，下面的行再读 `matrix[0][j]` 就全是 0，整个矩阵被抹平。所以要**倒序写回**，让标记通道最后才被覆盖。

> [!success]- 代码实现
> 
> ```python
> class Solution:
>     def setZeroes(self, matrix: List[List[int]]) -> None:
>         m, n = len(matrix), len(matrix[0])
>         col0 = any(matrix[i][0] == 0 for i in range(m))   # 第 0 列的答案先存走
> 
>         for i in range(m):                                # ① 打标记
>             for j in range(1, n):                         # j 从 1 开始
>                 if matrix[i][j] == 0:
>                     matrix[i][0] = matrix[0][j] = 0
> 
>         for i in range(m - 1, -1, -1):                    # ② 倒序写回
>             for j in range(n - 1, 0, -1):
>                 if matrix[i][0] == 0 or matrix[0][j] == 0:
>                     matrix[i][j] = 0
>             if col0:
>                 matrix[i][0] = 0                          # 第 0 列最后处理
> ```
> 
> - 关键变量：`col0` 是全题唯一的额外空间，$O(1)$。
> - 主流程：两遍扫描——**先全部记完，再统一写回**。绝不能边发现边清零，否则新写的 0 会被当成原始的 0 继续传染。
> - 为什么 `j` 从 1 开始：第 0 列的信息已交给 `col0`，`matrix[i][0]` 此刻只是标记位，不能再被当成数据读。

### 变体四：54. 螺旋矩阵（游标围出未处理区域）

按顺时针螺旋顺序返回矩阵所有元素。

这题没有技巧，只有**状态定义**：用 `top / bottom / left / right` 四个数描述「还没走过的那个矩形」，走完一条边就把对应边界推进一格。

![](assets/12.0%20螺旋边界收缩.svg)

> [!tip]- 核心思路：循环不变量是「四个边界围出的矩形全部未访问」
> 
> 每轮走四条腿，每条腿走完立刻收缩对应边界：
> 
> | 腿 | 遍历 | 固定坐标 | 走完 |
> | --- | --- | --- | --- |
> | ① 左 → 右 | `j` 从 `left` 到 `right` | `top` | `top += 1` |
> | ② 上 → 下 | `i` 从 `top` 到 `bottom` | `right` | `right -= 1` |
> | ③ 右 → 左 | `j` 从 `right` 到 `left` | `bottom` | `bottom -= 1` |
> | ④ 下 → 上 | `i` 从 `bottom` 到 `top` | `left` | `left += 1` |
> 
> **第 ③ ④ 条腿前必须再判一次边界**：走完 ① ② 之后 `top` 和 `right` 已经变了，剩余区域可能已经空掉。$1 \times 4$ 的单行矩阵 `[1,2,3,4]` 是最小反例——① 走完后 `top` 已经大于 `bottom`，若不判断，③ 会把 `4 3 2 1` 重复输出一遍。

> [!success]- 代码实现
> 
> ```python
> class Solution:
>     def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
>         top, bottom = 0, len(matrix) - 1
>         left, right = 0, len(matrix[0]) - 1
>         ans = []
>         while top <= bottom and left <= right:
>             for j in range(left, right + 1):           # ① 左 → 右
>                 ans.append(matrix[top][j])
>             top += 1
>             for i in range(top, bottom + 1):           # ② 上 → 下
>                 ans.append(matrix[i][right])
>             right -= 1
>             if top <= bottom:                          # 收缩后可能已空
>                 for j in range(right, left - 1, -1):   # ③ 右 → 左
>                     ans.append(matrix[bottom][j])
>                 bottom -= 1
>             if left <= right:
>                 for i in range(bottom, top - 1, -1):   # ④ 下 → 上
>                     ans.append(matrix[i][left])
>                 left += 1
>         return ans
> ```
> 
> - 免判断的替代写法：外层条件改成 `while len(ans) < m * n`，凑够元素立即返回——少两个 `if`，但要在每条腿内部检查是否已满。
> - 姊妹题 59 螺旋矩阵 II：把 `ans.append(...)` 换成 `matrix[...] = cnt` 再自增，骨架一字不改。

### 变体五：240. 搜索二维矩阵 II（游标围出未处理区域）

矩阵每行从左到右升序、每列从上到下升序，判断 `target` 是否存在。

![](assets/12.0%20右上角阶梯搜索.svg)

> [!tip]- 核心思路：右上角是唯一「两个方向单调相反」的位置
> 
> 站在右上角 `(0, n-1)`：**往左走变小，往下走变大**。于是每次比较都能排除一整行或一整列：
> 
> - `x > target`：这一列自上而下都不小于 `x`，整列删掉，`j -= 1`
> - `x < target`：这一行往左都不大于 `x`，整行删掉，`i += 1`
> 
> 从左上角出发就不行——往右和往下都变大，比 `target` 小时有两个方向可选，一个都排除不掉，那是分叉不是二分。左下角同理可用（往上变小、往右变大）。

> [!success]- 代码实现
> 
> ```python
> class Solution:
>     def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
>         m, n = len(matrix), len(matrix[0])
>         i, j = 0, n - 1                       # 从右上角出发
>         while i < m and j >= 0:
>             x = matrix[i][j]
>             if x == target:
>                 return True
>             if x > target:
>                 j -= 1                        # 删一列
>             else:
>                 i += 1                        # 删一行
>         return False
> ```
> 
> - 每步至少删掉一行或一列 $\Rightarrow$ 最多走 $m + n$ 步。
> - **和 74 搜索二维矩阵的区别**：74 额外保证「上一行末尾小于下一行开头」，摊平后完全有序，可以直接当长度 $mn$ 的数组做二分（见 [[3.0 二分查找 红蓝染色法]]）；240 只保证行内、列内有序，摊平后并不有序，二分不成立。看到二维有序矩阵先问一句：**是「全局有序」还是「行列各自有序」**。

### 变体六：75. 颜色分类 · 31. 下一个排列（Hot100「技巧」两题）

两题都是「原地重排」，各自只有一个记忆点，放在这里一并收掉。

> [!tip]- 75 颜色分类：荷兰国旗三指针
>
> 只有 0 / 1 / 2 三种值，要求一趟扫完、原地排好。用三个游标把数组切成四段——**这就是 [[13.0 排序算法 快排、归并与堆排]] 里三路划分的原型**：
>
> ```python
> class Solution:
>     def sortColors(self, nums: List[int]) -> None:
>         p0, i, p2 = 0, 0, len(nums) - 1
>         while i <= p2:
>             if nums[i] == 0:
>                 nums[i], nums[p0] = nums[p0], nums[i]
>                 p0 += 1
>                 i += 1
>             elif nums[i] == 2:
>                 nums[i], nums[p2] = nums[p2], nums[i]
>                 p2 -= 1              # i 不动！换过来的元素还没看过
>             else:
>                 i += 1
> ```
>
> 易错点和三路划分完全一样：**换到右边之后 `i` 不能前进**。

> [!tip]- 31 下一个排列：从右找「第一个下降位」
>
> 要的是字典序里恰好大一点的排列，所以改动要尽可能靠右、幅度尽可能小。三步：
>
> 1. 从右往左找第一个满足 `nums[i] < nums[i+1]` 的 `i`（**它右边是一段非升序的后缀**，已经是该后缀的最大排列，动不了）。
> 2. 再从右往左找第一个比 `nums[i]` 大的 `nums[j]`，交换两者——换上来的是「比它大的里面最小的那个」。
> 3. 把 `i` 右边的后缀**反转**成升序，让它取到最小值。
>
> ```python
> class Solution:
>     def nextPermutation(self, nums: List[int]) -> None:
>         n = len(nums)
>         i = n - 2
>         while i >= 0 and nums[i] >= nums[i + 1]:
>             i -= 1
>         if i >= 0:                              # i < 0 表示整个数组降序，直接翻成升序
>             j = n - 1
>             while nums[j] <= nums[i]:
>                 j -= 1
>             nums[i], nums[j] = nums[j], nums[i]
>         nums[i + 1:] = reversed(nums[i + 1:])   # 第三步：后缀反转，又是「对称反转」
> ```
>
> 第三步用的正是本篇变体一的手法——后缀本来就是降序，反转即得升序，不需要排序。
> 易错点：第一步的比较必须带等号 `nums[i] >= nums[i+1]`，否则遇到重复元素会停错位置；`i < 0` 时要跳过交换直接反转全部。

## 易错点

> [!warning]- 易错点
> 
> **1. 189 忘记 `k %= n`**
> `k` 可以大于 `n`，不取模时 `reverse(0, k-1)` 直接越界或反转空区间。
> 
> **2. 189 用 `nums = ...` 重新绑定**
> 返回 `None`、要求原地修改的题，赋值必须落在切片或下标上。写 `nums = x` 只改局部名字，调用方看不到，判题会报「未修改」。
> 
> **3. 48 转置内层写 `range(n)`**
> 每对元素交换两次 $\Rightarrow$ 矩阵原封不动。必须 `range(i + 1, n)` 只走上三角。
> 
> **4. 48 先翻转再转置**
> 得到的是逆时针 90°。两步有序，别背反。
> 
> **5. 73 边发现边清零**
> 新写进去的 0 会被后续扫描当成原始 0，一路传染，最后整个矩阵全 0。必须**两遍：先记后写**。
> 
> **6. 73 忽略 `matrix[0][0]` 的双重身份**
> 不用 `col0` 兜底，第一行或第一列会莫名其妙被多清或少清。
> 
> **7. 54 缺少 `if top <= bottom` / `if left <= right`**
> 单行或单列矩阵会重复输出。这是本题唯一的坑，也是面试官必造的用例。
> 
> **8. 240 从左上角开始**
> 逻辑上无法排除任何一半，退化成 $O(mn)$，甚至写不出正确的终止条件。

## 复杂度

> [!summary]- 复杂度
> 
> | 题 | 时间 | 空间 | 来源 |
> | --- | --- | --- | --- |
> | 189 | $O(n)$ | $O(1)$ | 三次反转共交换约 $n$ 次 |
> | 48 | $O(n^2)$ | $O(1)$ | 上三角约 $n^2/2$ 次交换 + 每行反转 |
> | 73 | $O(mn)$ | $O(1)$ | 两遍全扫，额外只有一个 `col0` |
> | 54 | $O(mn)$ | $O(1)$ 辅助 | 每格恰好入 `ans` 一次；返回数组不计入 |
> | 240 | $O(m+n)$ | $O(1)$ | 每步至少淘汰一行或一列 |
> 
> 240 的 $O(m+n)$ 优于「逐行二分」的 $O(m\log n)$，更优于朴素的 $O(mn)$。

## 一句话总结

这一族题不考算法，考的是**「$O(1)$ 空间下信息往哪儿放」**：放在对称位置（反转）、挤进原数据里（借位标记）、压缩成几个游标（边界收缩）——三条路走完，普通数组与矩阵就没有新题了。

## 模板归纳

**触发信号**：题目出现「原地 in-place」「不使用额外空间」「进阶：$O(1)$ 空间」，或者函数签名的返回类型是 `None`。

**四问定法**：

1. **要做的是「整体位移」吗？** $\to$ 想反转。位移 $k$ 位 = 三次反转；旋转 90° = 转置 + 翻行。
2. **要暂存一批标记吗？** $\to$ 想借位。先找哪一部分数据可以牺牲（首行首列 / 元素符号位 / 下标本身），再补一个变量处理借位处的冲突，最后**倒序写回**。
3. **要按特定顺序访问全部元素吗？** $\to$ 想边界收缩。定义未处理区域的四个游标，每步必须让区域严格变小，收缩后立刻重判边界。
4. **矩阵有序、要查找吗？** $\to$ 先分清全局有序（二分）还是行列各自有序（右上角阶梯）。

**通用自检**：写完先拿三组退化输入过一遍——**单行、单列、$1\times1$**。这一族题的 bug 几乎全部藏在这三组里。
