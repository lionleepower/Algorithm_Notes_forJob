# 普通栈：括号匹配、最小栈与表达式解码

## 解决什么问题

普通栈解决的是**嵌套结构**：最近打开的必须最先关闭（Last In First Out 天然对应「就近配对」）。

三种典型形态，Hot100 各一题：

| 形态 | 栈里存什么 | 题 |
| --- | --- | --- |
| **配对**：括号是否合法 | 待匹配的左括号 | 20. 有效的括号 |
| **携带附加信息**：查询历史极值 | `(值, 到此为止的最小值)` | 155. 最小栈 |
| **保存现场**：进入嵌套前把上下文压栈 | 外层的计数与已拼串 | 394. 字符串解码 |

第三种最重要——**递归能做的，栈都能做**，因为栈就是手写的调用栈。

## 变体一：20. 有效的括号

> [!tip]- 核心思路：右括号只能和「最近一个未匹配的左括号」配对
>
> 为什么是栈而不是计数：只有一种括号时，用计数器就够（`(` 加一 `)` 减一，中途不能为负、最后归零）。**一旦有三种括号，计数器无法表达「顺序」**——`([)]` 三个计数都平衡，但显然非法。
>
> 栈的语义是「**当前所有还没被关闭的左括号，按打开顺序**」。遇到右括号就检查栈顶是不是对应的那个左括号。
>
> **两个终止条件缺一不可**
> - 中途栈空或栈顶不匹配 $\to$ 立即 `False`
> - 扫描结束时**栈必须为空**（否则有左括号没关上，如 `"("`）

> [!success]- 代码实现
>
> ```python
> class Solution:
>     def isValid(self, s: str) -> bool:
>         pairs = {')': '(', ']': '[', '}': '{'}    # 右 -> 左，查表比写三个 if 干净
>         st = []
>         for ch in s:
>             if ch in pairs:                       # 右括号
>                 if not st or st.pop() != pairs[ch]:
>                     return False
>             else:                                 # 左括号
>                 st.append(ch)
>         return not st                             # 必须全部关闭
> ```
>更加直观一点:
>```python
	class Solution:
	    def isValid(self, s: str) -> bool:
	        if len(s) % 2 != 0:
	            return False
	        st = {'}': '{', ']': '[', ')': '('}
	        ans = []
	        for ch in s:
	            if ch not in st:
	                ans.append(ch)
	            else:
	                if not ans:
	                    return False
	                left = ans.pop()
	                if left != st[ch]:
	                    return False
	        return not ans
>```
> **主流程**：左括号入栈，右括号弹栈比对，最后查空。
> **易错位置**：`if not st` 必须写在 `st.pop()` **之前**（短路求值），否则空栈弹出会 `IndexError`。
> **奇数长度剪枝**：`if len(s) % 2: return False` 可以先挡掉一半用例。

## 变体二：155. 最小栈

要求 `push` / `pop` / `top` / `getMin` 全部 $O(1)$。

> [!tip]- 核心思路：栈顶不仅存值，还存「此刻的历史最小」
>
> 难点在 `getMin` 与 `pop` 的冲突：如果只存一个 `min` 变量，弹出最小值后就**恢复不了上一个最小值**——历史信息丢了。
>
> 解法是把「最小值」也做成**与栈同步的历史**：
>
> - **写法 A（辅助栈同步压）**：`min_st[i] = min(前 i+1 个元素)`。每次 `push(x)` 同时 `min_st.append(min(x, min_st[-1]))`，`pop` 两个一起弹。最简单、最不易错。
> - **写法 B（单栈存元组）**：栈里直接存 `(值, 当前最小)`。本质相同，少维护一个结构。
>
> **不变量**：`min_st[i]` 恒等于主栈前 `i+1` 个元素的最小值——因此 `pop` 时不需要任何重算，直接同步弹出即可。

> [!success]- 代码实现
>
> ```python
> class MinStack:
>     def __init__(self):
>         self.st = []
>         self.min_st = [float('inf')]      # 哨兵：省掉「空栈」的分支判断
>
>     def push(self, val: int) -> None:
>         self.st.append(val)
>         self.min_st.append(min(val, self.min_st[-1]))
>
>     def pop(self) -> None:
>         self.st.pop()
>         self.min_st.pop()                 # 两栈永远等长（不含哨兵）
>
>     def top(self) -> int:
>         return self.st[-1]
>
>     def getMin(self) -> int:
>         return self.min_st[-1]
> ```
>
> **哨兵 `inf` 的作用**：让 `push` 里的 `self.min_st[-1]` 在空栈时也合法——和 [[4.2 删除链表]] 里 dummy 节点消除头结点分支是同一个技巧。
> **面试追问**：能不能省掉辅助栈？可以——存**差值**（`st` 存 `val - min`，负数说明刷新了最小值），但要处理溢出且极易写错，说得出思路即可，不建议现场写。

## 变体三：394. 字符串解码

`"3[a2[c]]"` $\to$ `"accaccacc"`。

> [!tip]- 核心思路：双栈 = 手写递归的「保存现场 / 恢复现场」
>
> 嵌套的本质是：**遇到 `[` 就进入一层新的上下文，遇到 `]` 就回到上一层并把结果带回去。** 这正是函数调用。
>
> 用栈手写时，「现场」由两部分组成，所以要两个栈：
>
> - `num_st`：外层还没用掉的**重复次数**
> - `str_st`：外层已经拼好的**前缀字符串**
>
> 四种字符，四种动作：
>
> | 读到 | 动作 | 为什么 |
> | --- | --- | --- |
> | 数字 | `num = num * 10 + int(ch)` | 可能是多位数，`10[...]` |
> | `[` | 把 `num` 和 `cur` 双双压栈，然后**清零清空** | 进入新一层，当前层从空白开始 |
> | `]` | 弹出 `k` 和 `prev`，`cur = prev + cur * k` | 本层拼完，乘上倍数接回外层 |
> | 字母 | `cur += ch` | 累积到当前层 |
>
> **只有 `[` 才清空 `cur`、只有 `]` 才做乘法**——把这两句记牢，代码就不会乱。
>
> 递归写法（`dfs` 返回「本层解析结果 + 停在哪」）本质相同，栈写法只是把递归栈显式化了。

> [!example]- 示例推演：`"3[a2[c]]"`
>
> ```text
> 读 3      num = 3
> 读 [      压栈 num_st=[3]  str_st=[""]      num=0  cur=""
> 读 a      cur = "a"
> 读 2      num = 2
> 读 [      压栈 num_st=[3,2] str_st=["","a"] num=0  cur=""
> 读 c      cur = "c"
> 读 ]      弹 k=2 prev="a"  ->  cur = "a" + "c"*2 = "acc"
> 读 ]      弹 k=3 prev=""   ->  cur = "" + "acc"*3 = "accaccacc"
>
> 答案 "accaccacc"
> ```

> [!success]- 代码实现
>
> ```python
> class Solution:
>     def decodeString(self, s: str) -> str:
>         num_st, str_st = [], []
>         num, cur = 0, ""
>         for ch in s:
>             if ch.isdigit():
>                 num = num * 10 + int(ch)     # 多位数
>             elif ch == '[':
>                 num_st.append(num)           # 保存现场
>                 str_st.append(cur)
>                 num, cur = 0, ""             # 新一层从空白开始
>             elif ch == ']':
>                 k = num_st.pop()             # 恢复现场
>                 cur = str_st.pop() + cur * k # 本层结果乘倍数，接回外层
>             else:
>                 cur += ch
>         return cur
> ```
>
> **关键变量**：`cur` 永远表示「**当前这一层**已经拼好的串」，`num` 表示「**下一个** `[` 的倍数」。
> **易错位置**：`]` 分支里的顺序是 `str_st.pop() + cur * k`，写反成 `cur * k + str_st.pop()` 会把外层前缀甩到后面。

## 易错点

> [!warning]- 易错点
>
> **1. 20：空栈就 `pop`**
> 输入 `"]"` 会 `IndexError`。判空必须短路在前。
>
> **2. 20：忘了最后查空**
> `"("` 全程没触发任何检查，函数会返回 `True`。
>
> **3. 155：只用一个 `min` 变量**
> `push(1) push(2) pop()` 之后 `getMin` 就废了——最小值的**历史**没保存。
>
> **4. 155：辅助栈只在「更小」时才压**
> 那样两栈长度不同步，`pop` 时要额外判断「弹出的是不是当前最小」，边界（相等值）极易写错。**同步压同步弹**最稳。
>
> **5. 394：数字只读一位**
> `"12[a]"` 会解析成 `1` 和 `2`。必须 `num = num * 10 + d` 累积。
>
> **6. 394：在 `[` 处忘记清空 `cur`**
> 外层前缀会被内层重复乘一遍。清空的同时也别忘了 `num = 0`。
>
> **7. 把栈当队列用**
> Python 里 `list.pop()` 是弹尾（栈），`list.pop(0)` 是弹头且 $O(n)$。需要队列请用 `deque`，见 [[Python_deque]]。

## 复杂度

> [!summary]- 复杂度
>
> - **20**：时间 $O(n)$ —— 每个字符入栈出栈各一次；空间 $O(n)$ —— 最坏全是左括号。
> - **155**：全部操作 $O(1)$ —— 只做尾部读写；空间 $O(n)$ —— 辅助栈与主栈等长。
> - **394**：时间 $O(\text{输出长度})$ —— 字符串拼接的总代价由最终结果决定，而非输入长度；空间 $O(n)$ —— 嵌套深度加上各层已拼前缀。

## 一句话总结

栈解决的永远是「**最近的那个**」——最近未匹配的左括号、最近一次的最小值、最近进入的那一层上下文；**双栈解码题的本质就是把递归的保存/恢复现场手写出来**。

## 模板归纳

**触发信号 $\to$ 条件反射**

- 「括号 / 标签 / 嵌套是否合法」$\to$ 栈存待匹配的左半边
- 「$O(1)$ 查历史极值」$\to$ 栈里除了值再存一份**同步的聚合量**
- 「`k[...]` 这类嵌套展开、多层嵌套的表达式」$\to$ **双栈保存现场**，或直接写递归
- 「最近的一个更大 / 更小元素」$\to$ 不是普通栈，去看 [[2.0 单调栈与单调队列]]

**落笔三步**

1. 先用一句话写死「**栈里的每个元素代表什么**」——这一句写不出来就还没想清楚。
2. 列出所有输入字符 / 事件类型，逐个决定「压、弹、还是改栈顶」。
3. 循环结束后**必须检查栈是否为空**，剩下的元素往往正是未闭合的非法部分。
