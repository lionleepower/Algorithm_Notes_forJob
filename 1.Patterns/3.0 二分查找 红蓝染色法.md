# 二分查找：红蓝染色法

## 解决什么问题

二分不要求「数组有序」，只要求**判定结果单调**——把答案空间染成红蓝两段，找红蓝交界处。

```text
红红红红 | 蓝蓝蓝蓝
        ↑ 要找的交界
```

两个识别信号，缺一不可：

- **答案空间有范围**（数组下标 `0..n`，或答案值域 `0..upper`）
- **判定函数单调**：`False False False True True True`（或反过来），不能一会儿真一会儿假

按二分的**对象**分三类，也是本专题的三篇：在**数组下标**上二分（本篇）→ 在**答案值域**上二分（[[3.1 二分答案]]）→ 在**非整体有序**的数组上二分（[[3.2 二分查找 峰值与旋转]]）。

## 统一模板：左开右开 `(left, right)`

**本知识库统一用开区间**。它不需要写 `mid + 1` / `mid - 1`，两个边界含义对称、最难写错，`3.1`、`3.2` 全部沿用这一套。

> [!tip]- 核心：left 是最后一个红，right 是第一个蓝
> 
> 两个指针**永远**代表已确定的颜色，这就是全部不变量：
> 
> ```text
> left  = 已知的最后一个红色位置（不满足）  初始 -1，是虚拟的"红哨兵"
> right = 已知的第一个蓝色位置（满足）      初始 n，是虚拟的"蓝哨兵"
> ```
> 
> 初始值取 `-1` 和 `n` 正是因为它们**在数组外**，代表「还没有任何真实位置被确认」。循环条件 `left + 1 < right` 的含义是「两者之间还有未染色的位置」；结束时 `left + 1 == right`，红蓝贴在一起，`right` 就是第一个蓝色。
> 
> 每轮把 `mid` 染色后并入对应边界，**不需要 ±1**——因为开区间里 `left`、`right` 本身不属于待搜索范围，`mid` 直接赋值即可。

> [!success]- 模板代码
> 
> ```python
> def binary_search(nums, check):
>     left, right = -1, len(nums)      # 红哨兵、蓝哨兵，都在数组外
> 
>     while left + 1 < right:          # 中间还有未染色的位置
>         mid = (left + right) // 2
>         if check(mid):
>             right = mid              # mid 是蓝色（满足）
>         else:
>             left = mid               # mid 是红色（不满足）
> 
>     return right                     # 第一个蓝色位置
> ```
> 
> - 主流程：每轮把 `mid` 染成红或蓝，并入对应边界，区间减半。
> - 关键不变量：`left` 恒红、`right` 恒蓝，循环中始终成立。
> - 返回值：找**第一个满足**返回 `right`；找**最后一个不满足**返回 `left`。二者永远相邻。

## 关键方法：先定义 `check(mid)`，别纠结等号

写二分卡壳，几乎都卡在「这里到底要不要加等号」。**这个问题问反了**——等号不是想出来的，是从 `check` 推出来的。

> [!tip]- 四步推导法（最重要的一节）
> 
> 按顺序问，机械得出代码，不需要背 `>` / `>=`：
> 
> 1. 我要找的「**第一个满足**」是什么？
> 2. `check(mid)` 怎么写？（= mid 是否已经满足要求 = 是否为蓝色）
> 3. `not check(mid)` 是什么？（自动取反，等号自然归位）
> 4. 落笔 `if not check(mid): left = mid`，`else: right = mid`
> 
> **等号从来没有消失，它只是被包含在 `else` 里。**

> [!example]- 常见目标对照表
> 
> | 目标 | `check(mid)`（蓝色） | `not check(mid)`（红色） | 代码里的 `if` |
> | --- | --- | --- | --- |
> | 第一个 `>= target` | `nums[mid] >= target` | `nums[mid] < target` | `if nums[mid] < target:` |
> | 第一个 `> target` | `nums[mid] > target` | `nums[mid] <= target` | `if nums[mid] <= target:` |
> | 第一个 `>= n - i`（H 指数） | `citations[mid] >= n - mid` | `citations[mid] < n - mid` | `if citations[mid] < n - mid:` |
> | 第一个可行速度 | `hours(mid) <= h` | `hours(mid) > h` | `if hours(mid) > h:` |
> | 第一个可行容量 | `days(mid) <= D` | `days(mid) > D` | `if days(mid) > D:` |
> 
> 后两行已经是 [[3.1 二分答案]] 的形态——`mid` 不再是下标，而是候选答案，但推导过程一模一样。

## 四种查询：一个 lower_bound 全搞定

> [!success]- lower_bound 与三个变形
> 
> ```python
> def lower_bound(nums, target):
>     """返回第一个 >= target 的位置；不存在则返回 len(nums)"""
>     left, right = -1, len(nums)
>     while left + 1 < right:
>         mid = (left + right) // 2
>         if nums[mid] < target:       # 红：还不满足
>             left = mid
>         else:                        # 蓝：>= target
>             right = mid
>     return right
> ```
> 
> 另外三种查询**都不用另写模板**，全部转化成 `lower_bound`（以下适用于**整数**数组）：
> 
> | 查询 | 转化写法 |
> | --- | --- |
> | 第一个 `>= target` | `lower_bound(target)` |
> | 第一个 `> target` | `lower_bound(target + 1)` |
> | 最后一个 `< target` | `lower_bound(target) - 1` |
> | 最后一个 `<= target` | `lower_bound(target + 1) - 1` |
> 
> Python 标准库直接对应：`bisect_left(nums, x)` 就是 `lower_bound`，`bisect_right(nums, x)` 就是第一个 `> x`。面试可直接用，笔试建议能手写。

> [!example]- 34. 在排序数组中查找元素的第一个和最后一个位置
> 
> ```python
> class Solution:
>     def searchRange(self, nums: list[int], target: int) -> list[int]:
>         start = lower_bound(nums, target)
>         if start == len(nums) or nums[start] != target:   # 必须验存在性
>             return [-1, -1]
>         end = lower_bound(nums, target + 1) - 1           # 最后一个 target
>         return [start, end]
> ```
> 
> 推演 `nums = [5,7,7,8,8,10], target = 8`：
> 
> ```text
> lower_bound(8) = 3          # 第一个 >= 8
> lower_bound(9) = 5          # 第一个 >= 9，即第一个 > 8
> end = 5 - 1 = 4
> 答案 [3, 4]
> ```
> 
> 要点：`lower_bound` 只保证「>= target」，**不保证等于**，所以必须检查 `nums[start] != target`。

> [!example]- 1385. 两个数组间的距离值
> 
> 对每个 `x`，判断 `arr2` 中是否存在数落在 $[x-d,\ x+d]$ 内——用二分找区间左端，只需一次查询。
> 
> ```python
> from bisect import bisect_left
> 
> class Solution:
>     def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
>         arr2.sort()                                  # 二分的前提
>         ans = 0
>         for x in arr1:
>             i = bisect_left(arr2, x - d)             # 第一个 >= x-d
>             if i == len(arr2) or arr2[i] > x + d:    # 区间内无元素
>                 ans += 1
>         return ans
> ```
> 
> 要点：第一个 `>= x-d` 的数若已经 `> x+d`，说明整个区间是空的——只查左端就够，不必两次二分。

## 三种区间写法对照

> [!summary]- 为什么统一用开区间
> 
> | 写法 | 初始化 | 循环条件 | 蓝色时 | 红色时 | 返回 |
> | --- | --- | --- | --- | --- | --- |
> | `[left, right]` 闭 | `0, n-1` | `left <= right` | `right = mid - 1` | `left = mid + 1` | `left` |
> | `[left, right)` 半开 | `0, n` | `left < right` | `right = mid` | `left = mid + 1` | `left` |
> | **`(left, right)` 开** | **`-1, n`** | **`left + 1 < right`** | **`right = mid`** | **`left = mid`** | **`right`** |
> 
> 三种都对，但开区间有两个独占优势：**两边都不用 ±1**（闭区间两边都要，半开区间还差一边），以及**两个指针语义完全对称**（一红一蓝），改判定条件时不必重新推边界。
> 
> 唯一代价：初始值 `-1` 和 `n` 看着别扭——记住它们是「数组外的哨兵」就顺了。**三种混用是最大的错误来源，选定一种用到底。**

## 易错点

> [!warning]- 易错点
> 
> - **三种区间写法混用**：开区间写成 `right = mid - 1`，或闭区间写成 `right = mid`，都会死循环或漏解。选定 `(left, right)` 就全程 `left = mid` / `right = mid`，一个 ±1 都不要出现。
> - **忘记验证存在性**：`lower_bound` 返回的是「第一个 >= target」的位置，**不保证等于 target**，也可能返回 `n`（全都小于）。取值前必须 `if i == len(nums) or nums[i] != target`。
> - **纠结等号而不是先定义 check**：正确顺序是「先想清楚什么是蓝色 → 取反写进 `if`」，等号会自动归位；反过来硬凑等号必错。
> - **误以为二分只能用于有序数组**：二分的真正前提是**判定单调**。数组无序但 `check` 单调（如 [[3.1 二分答案]]）照样能二分；反之数组有序但判定不单调也不行。
> - **找最后一个 target 时硬写右边界模板**：不要另写一套，转化成 `lower_bound(target + 1) - 1` 最稳（仅限整数）。
> - **`bisect_left` / `bisect_right` 记反**：`bisect_left` = 第一个 `>= x`，`bisect_right` = 第一个 `> x`。

## 复杂度

> [!summary]- 复杂度
> 
> - 时间 $O(\log n)$：每轮判定把区间**严格减半**，`left + 1 < right` 保证区间至少有 2 个待定位置才继续，不会死循环。
> - 空间 $O(1)$：只用两个指针，迭代无递归栈。
> - 34 题：两次 `lower_bound`，仍是 $O(\log n)$。
> - 1385 题：排序 $O(m \log m)$ + 每个 `x` 一次二分 $O(n \log m)$，合计 $O((n+m) \log m)$。
> - **提醒**：若为了二分而先排序，总复杂度被 $O(n \log n)$ 的排序主导，二分只省了查询那一步。

## 一句话总结

二分的本质不是「猜中某个值」，而是**在单调的判定结果上维护红蓝两个边界，逼出交界点**——先定义 `check(mid)`，等号自然归位。

## 模板归纳

看到「**有序数组找边界**」或「**第一个 / 最后一个满足某条件**」，四步落笔：

1. 确认**判定单调**（前红后蓝），否则不能二分。
2. 定义 `check(mid) = mid 是否已满足`（即是否为蓝色）。
3. 套开区间模板，`if not check(mid): left = mid`，`else: right = mid`。
4. 定返回值：第一个满足 → `right`；最后一个不满足 → `left`。需要取值时先验存在性。

```python
# 二分通用骨架（左开右开）
left, right = -1, n              # 红哨兵、蓝哨兵
while left + 1 < right:
    mid = (left + right) // 2
    if not check(mid):
        left = mid               # 红
    else:
        right = mid              # 蓝
return right                     # 第一个蓝；要最后一个红则 return left
```

条件反射：

```text
第一个 >= target      → lower_bound(target)
第一个 > target       → lower_bound(target + 1)
最后一个 <= target    → lower_bound(target + 1) - 1
最小可行值 / 最大可行值 → 二分答案，见 3.1
数组不是整体有序       → 重新定义 is_blue，见 3.2
```
