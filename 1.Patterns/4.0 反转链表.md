# 反转链表：三指针模板与区间反转

## 解决什么问题

链表题里凡是出现「逆序」「倒过来」「每 k 个一组」，几乎都归结为同一个动作：**逐个改写 `next` 指针的方向**。识别信号：

```text
单链表 + 要求改变节点顺序 + 不允许（或没必要）交换节点值
```

先钉死一个前提：**反转的是指针，不是值**。交换值在链表上既慢又容易在节点带额外字段时出错，面试默认写改指针版。

三道题是同一个模板的三层加料，**内层那四行一个字都不用改**：

| 题号 | 难度 | 相对模板加了什么 |
| --- | --- | --- |
| **206. 反转链表** | 简单 | 模板本身 |
| 92. 反转链表 II | 中等 | 只反转 `[left, right]`，多出「找前驱」+「接回去」 |
| 25. K 个一组翻转链表 | 困难 | 把 92 重复做，多出「够不够 k 个」+「p0 往前挪」 |

## 统一模板：三个指针，一轮四步

![](assets/4.0%20三指针一轮循环.svg)

> [!tip]- 核心思路：全部信息量都在这条不变量里
> 
> ```text
> pre：已经反转好的那段链表的头
> cur：还没反转的那段链表的头
> nxt：临时保存 cur 的后继，防止断链
> ```
> 
> 每一轮循环只做一件事：**把 `cur` 这一个节点从原链表里摘下来，接到 `pre` 前面**。四行代码分别对应「存下一个 → 反指前一个 → `pre` 前进 → `cur` 前进」。
> 
> **为什么必须先 `nxt = cur.next`**：下一句 `cur.next = pre` 会把 `cur` 的后继覆盖掉。`1 -> 2 -> 3` 里如果不先记住 `2`，执行完就变成 `1 -> None`，`2 -> 3` 这条路再也找不到了。
> 
> **为什么返回 `pre` 不是 `cur`**：循环退出的条件就是 `cur` 变成 `None`，此刻 `pre` 才是新头。

> [!example]- 推演 1 → 2 → 3
> 
> 只看不变量的演化，四行代码的细节可以先不管：
> 
> ```text
> pre = None,             cur = 1 -> 2 -> 3
> pre = 1,                cur = 2 -> 3
> pre = 2 -> 1,           cur = 3
> pre = 3 -> 2 -> 1,      cur = None      ← 退出，返回 pre
> ```
> 
> 边界一并验证：空链表时 `cur = head = None`，循环体一次都不进，直接返回 `pre = None` ✓；单节点时循环一轮，返回它自己 ✓。**两个边界都被初始值天然兜住，不需要任何特判。**

> [!success]- 206. 反转链表（模板本体）
> 
> ```python
> class Solution:
>     def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         pre = None
>         cur = head
>         while cur:
>             nxt = cur.next      # 存下一个
>             cur.next = pre      # 反指前一个
>             pre = cur           # pre 前进
>             cur = nxt           # cur 前进
>         return pre              # cur 已是 None，pre 才是新头
> ```
> 
> - 主流程：`cur` 扫一遍原链表，每轮反转一个 `next`。
> - 关键变量：`pre` 已反转段的头，`cur` 未反转段的头，`nxt` 防断链的临时存档。
> - 易错位置：漏掉 `nxt`；返回写成 `cur`。
> - 变量移动与 `.next` 赋值的区别（为什么 `p0 = p0.next` 不改链表结构）见 [[Python_链表指针与区间反转]]。

## 变体一：92. 反转链表 II（区间反转）

只反转第 `left` 到第 `right` 个节点。相对模板多两件事：**找到区间前驱 `p0`**，以及**反转完把三段接回去**。

![](assets/4.0%20区间反转接回.svg)

> [!tip]- 三个连接点，两句接回，顺序不能反
> 
> 内层反转结束的那一刻，四个变量各自站在哪里是固定的：
> 
> | 变量 | 位置 |
> | --- | --- |
> | `p0` | 区间前驱，**全程没动过** |
> | `p0.next` | 反转**前**的区间头 → 反转后变成区间**尾** |
> | `pre` | 反转后的区间**新头** |
> | `cur` | 区间后面的第一个节点 |
> 
> 于是接回只需两句：
> 
> ```python
> p0.next.next = cur      # ① 旧头（现在是尾）接上后半段
> p0.next = pre           # ② 前驱接上新头
> ```
> 
> **顺序反了必错**：先写 ② 的话，`p0.next` 立刻改指向新头，「原区间头」这个唯一的把手就被弄丢了，再也没办法让它接上 `cur`。
> 
> **为什么要 `dummy`**：`left = 1` 时区间前驱不存在，得单独处理头节点。加一个哨兵节点后 `p0` 一定有值，头节点变不变都统一返回 `dummy.next`。

> [!success]- 92 代码
> 
> ```python
> class Solution:
>     def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
>         dummy = ListNode(0, head)
>         p0 = dummy
>         for _ in range(left - 1):        # 走 left-1 步，停在区间前驱
>             p0 = p0.next
> 
>         pre = None
>         cur = p0.next
>         for _ in range(right - left + 1):  # 闭区间节点数
>             nxt = cur.next
>             cur.next = pre
>             pre = cur
>             cur = nxt
> 
>         p0.next.next = cur               # ① 旧头接后段
>         p0.next = pre                    # ② 前驱接新头
>         return dummy.next
> ```
> 
> - 主流程：定位前驱 → 反转固定圈数 → 两句接回。
> - 关键变量：`p0` 是整道题的锚点，反转过程中**绝对不能动它**。
> - 易错位置：`range(left - 1)` 少减 1、`range(right - left + 1)` 少加 1、两句接回写反、返回 `head` 而不是 `dummy.next`。
> - 与 206 的唯一区别：循环条件从 `while cur`（走到底）换成 `for _ in range(...)`（走固定步数）。

## 变体二：25. K 个一组翻转链表

把 92 重复执行：每 `k` 个节点反转一次，**不足 k 个保持原样**。

> [!tip]- 相对 92 只多两件事
> 
> 1. **先数长度 `n`**，循环条件写 `while n >= k`——这是「不足 k 个不反转」的唯一实现方式，不能写 `while cur`。
> 2. **`p0` 要往前挪**：92 只反转一次，`p0` 全程不动；25 有很多组，每组接回后 `p0` 必须移动到**本组反转后的尾部**，才能当下一组的前驱。
> 
> 而「本组反转后的尾部」正好就是**本组反转前的头**，也就是接回之前的 `p0.next`。所以要在改写 `p0.next` **之前**把它存下来：
> 
> ```python
> nxt = p0.next          # 本组旧头 = 本组新尾 = 下一组的 p0
> p0.next.next = cur     # ① 和 92 完全一样
> p0.next = pre          # ②
> p0 = nxt               # 新增：p0 挪到本组尾部
> ```

> [!success]- 25 代码
> 
> ```python
> class Solution:
>     def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
>         n = 0
>         cur = head
>         while cur:                       # 先数出链表长度
>             n += 1
>             cur = cur.next
> 
>         dummy = ListNode(0, head)
>         p0 = dummy
>         cur = head
> 
>         while n >= k:                    # 剩余节点够一组才反转
>             n -= k
>             pre = None
>             for _ in range(k):           # 内层就是 206 的四行
>                 nxt = cur.next
>                 cur.next = pre
>                 pre = cur
>                 cur = nxt
> 
>             nxt = p0.next                # 存下本组旧头（= 新尾 = 下一组的前驱）
>             p0.next.next = cur
>             p0.next = pre
>             p0 = nxt
> 
>         return dummy.next
> ```
> 
> - 主流程：数长度 → 每轮反转 k 个 → 接回 → `p0` 挪到本组尾。
> - 关键变量：`n` 是**剩余**节点数（每组开头 `n -= k`），`p0` 是本组前驱，`cur` 是下一组起点。
> - 易错位置：外层 `nxt = p0.next` 与内层循环的 `nxt` 重名，读代码时容易看串——它俩作用完全不同，写的时候可以把外层改名成 `p0_next` 提高可读性。

## 易错点

> [!warning]- 易错点
> 
> - **忘记保存 `nxt`**：写成 `cur.next = pre` 后再 `cur = cur.next`，此时 `cur.next` 已经被改成 `pre`，等于原地掉头，链表后半段直接丢失。
> - **返回 `cur` 而不是 `pre`**：循环退出时 `cur` 恒为 `None`，返回它就是返回空链表。
> - **区间反转不用 `dummy`**：`left = 1` 时头节点会变，没有哨兵就得额外分支，很容易写乱。凡是「头节点可能改变」的链表题，先写 `dummy`。
> - **接回顺序写反**：必须先 `p0.next.next = cur` 再 `p0.next = pre`。反过来会丢掉「原区间头」这个把手。
> - **区间长度算错**：闭区间 `[left, right]` 的节点数是 `right - left + 1`；`p0` 要走的是 `left - 1` 步。这两个 `1` 各有各的来源，别互相抄。
> - **25 用 `while cur` 当外层条件**：会把最后不足 `k` 个的尾巴也反转掉，与题意相反。必须先数长度，用 `while n >= k`。
> - **25 忘了挪 `p0`**：不挪的话第二组会接错位置，结果通常表现为链表只反转了第一组，或者直接成环。

## 复杂度

> [!summary]- 复杂度
> 
> 三题同阶：
> 
> - 时间 $O(n)$——每个节点的 `next` 恰好被改写一次（25 多一趟数长度，仍是 $O(n)$）。
> - 空间 $O(1)$——只用常数个指针变量，没有开新节点，也没有递归栈。
> 
> 补充：206 也可以写成递归版，但空间会退化成 $O(n)$ 的递归栈；面试默认写迭代版。

## 一句话总结

反转链表的全部功夫在一条不变量上——**`pre` 是已反转段的头、`cur` 是未反转段的头**；区间反转和 k 组反转只是在这条不变量外面套了两层壳：**用 `dummy` + `p0` 找到前驱，反转完按「旧头接后段、新头接前段」的顺序接回去**。

## 模板归纳

看到「**单链表 + 要求逆序 / 局部逆序 / 每 k 个一组**」，三步落笔：

1. **先写内核**（任何反转题都一样，闭着眼默写）：

```python
pre = None
cur = head
while cur:                  # 局部反转就换成 for _ in range(圈数)
    nxt = cur.next
    cur.next = pre
    pre = cur
    cur = nxt
```

2. **判断要不要 `dummy`**：只要头节点**可能**改变（整条反转、`left = 1`、k 组反转）就先建哨兵，返回统一写 `dummy.next`。
3. **要接回就记三个点**：`p0`（前驱，不动）、`pre`（新头）、`p0.next`（旧头 = 新尾）。接回永远是这两句，顺序固定：

```python
p0.next.next = cur      # 旧头接后段
p0.next = pre           # 前驱接新头
# 多组反转再加一句：p0 = 旧头（挪到本组尾部）
```
