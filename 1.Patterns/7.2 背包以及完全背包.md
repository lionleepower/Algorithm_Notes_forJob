# 背包与完全背包

## 解决什么问题

看到「一堆物品，每个有体积/价值，在容量约束下求最值或方案数」就是背包。识别信号只有一个分岔口：**每个物品能选几次**。

- **0-1 背包**：每个物品最多选 1 次 → 转移用 `dfs(i-1, ...)`（选完就跳到上一个物品）。
- **完全背包**：每个物品可选无限次 → 转移用 `dfs(i, ...)`（选完还停在当前物品）。

**只差 `i-1` 和 `i` 一个字**，其余骨架完全一样。剩下的变化都在两个维度上组合：求**最值**还是**计数**、约束是**恰好/至多/至少**。

## 统一模板

> [!tip]- 核心思路：一个骨架，两处开关
> 
> 合同：$dfs(i, c) = \text{只用前 } i+1 \text{ 个物品、容量为 } c \text{ 时的答案}$。对第 `i` 个物品「选或不选」，不重不漏：
> 
> - **不选**：`dfs(i-1, c)`
> - **选**：0-1 背包 `dfs(i-1, c-w[i])`；完全背包 `dfs(i, c-w[i])`
> 
> 两个开关决定这是哪一类题：
> 
> | 开关 | 求最值 | 求计数 |
> | --- | --- | --- |
> | `combine` | `max` / `min` | `+` |
> | base `i<0` 且 `c==0` | `0` | `1`（唯一空方案） |
> | base `i<0` 且 `c!=0` | `0` 或 `inf` | `0` |
> 
> 「求最值时空集算 0，求方案数时空集算 1」——这条和 [[7.1 DP 打家劫舍]] 里 `max` 与 `+` 的区别是配套的。

> [!success]- 模板代码：0-1 与完全，只差一个下标
> 
> ```python
> from functools import cache
> 
> # === 0-1 背包骨架（物品选一次）===
> @cache
> def dfs(i, c):
>     if i < 0:
>         return 0 if c == 0 else 0      # 计数=1/0，最值=0/inf，按题调
>     if c < w[i]:
>         return dfs(i - 1, c)           # 容量不够，只能不选
>     return combine(dfs(i - 1, c),      # 不选
>                    dfs(i - 1, c - w[i]))  # 选：跳到 i-1
> 
> # === 完全背包骨架（物品选无限次）===
> @cache
> def dfs(i, c):
>     if i < 0:
>         return 0 if c == 0 else 0
>     if c < w[i]:
>         return dfs(i - 1, c)
>     return combine(dfs(i - 1, c),      # 不选：离开物品 i
>                    dfs(i,     c - w[i]))  # 选：仍停在 i，可再选
> ```
> 
> - 主流程：唯一区别是「选」分支的第一个参数 `i-1`（0-1）还是 `i`（完全）。
> - `@cache` 自动记忆化，机制见 [[Python_cache]]；能这样缓存的前提是无后效性，见 [[重叠子问题与无后效性]]。

## 变体一：494. 目标和（0-1 背包 · 计数）

给每个数分配 `+`/`-`，使总和等于 `target`，问方案数。**关键是先把「加减号」转成「选子集」**，之后就是标准 0-1 背包计数。

> [!tip]- 为什么 `target += sum(nums)` 再 `//= 2`
> 
> 分配符号 = 把 `nums` 分成两堆：拿 `+` 的堆 `P`、拿 `-` 的堆 `N`。
> 
> $$sum(P) - sum(N) = target,\quad sum(P) + sum(N) = sum(nums)$$
> 
> 两式相加消掉 `N`：$2\,sum(P) = target + sum(nums)$，即 $sum(P) = \dfrac{target + sum(nums)}{2}$。
> 
> 于是原问题变成「选一个子集，和**恰好**等于新 `target`，有几种选法」——每个数只有「进不进 P 堆」两种决策，正是 0-1 背包。选定 P 堆，N 堆自动确定，符号方案数 = 子集选法数，一一对应。
> 
> 两行剪枝的来历：`target < 0` 因为 `sum(P)` 是非负数之和不可能为负；`target % 2` 因为翻转任一数的符号，总和变化恒为 $2x$（偶数），奇偶性被锁死——`target` 与 `sum(nums)` 奇偶不同则无解。

> [!success]- 递归 + 记忆化（面试主推）
> 
> ```python
> from functools import cache
> from typing import List
> 
> class Solution:
>     def findTargetSumWays(self, nums: List[int], target: int) -> int:
>         target += sum(nums)
>         if target < 0 or target % 2:      # 恰好语义专属的预检查
>             return 0
>         target //= 2
>         n = len(nums)
> 
>         @cache
>         def dfs(i, c):
>             if i < 0:
>                 return 1 if c == 0 else 0   # 计数：预算刚好花光算 1 种
>             if c < nums[i]:
>                 return dfs(i - 1, c)
>             return dfs(i - 1, c) + dfs(i - 1, c - nums[i])
>         return dfs(n - 1, target)
> ```
> 
> - `dfs(i, c)` 语义：用 `nums[0..i]` 凑出和为 `c` 的子集有几种。骨架和 [[6.1 子集型回溯]] 的「选/不选」一致，只是把「收集方案」换成「数量相加」。

> [!example]- 恰好 / 至多 / 至少：0-1 计数三兄弟
> 
> 把 `c` 想成「剩余额度」，三者只差**边界**和**容量越界的处理**：
> 
> | 变体 | c 的语义 | c 变负 | 边界 `i < 0` |
> | --- | --- | --- | --- |
> | 恰好 | 必须精确归零 | 非法，剪掉 | `c == 0` 返回 1 |
> | 至多 | 不能超支 | 非法，剪掉 | 恒返回 1 |
> | 至少 | 必须还清的欠款 | 合法，`clamp` 到 0 | `c == 0` 返回 1 |
> 
> ```python
> # 至多：只改边界，走到头无条件算一种（空选也合法）
> def dfs(i, c):
>     if i < 0:
>         return 1
>     if c < nums[i]:
>         return dfs(i - 1, c)
>     return dfs(i - 1, c) + dfs(i - 1, c - nums[i])
> 
> # 至少：允许透支，把负数状态折叠到 0（欠款还清后都等价）
> def dfs(i, c):
>     if i < 0:
>         return 1 if c == 0 else 0    # 有了 max(...,0)，c==0 表示"已达标(含超额)"
>     return dfs(i - 1, c) + dfs(i - 1, max(c - nums[i], 0))
> ```
> 
> 自检恒等式（口头推理素材）：$至多(c)=\sum_{k=0}^{c}恰好(k)$，$至少(c)=2^{n}-至多(c-1)$。

## 变体二：322. 零钱兑换（完全背包 · 求最小个数）

硬币面额可重复使用，求凑出 `amount` 的**最少硬币数**。识别为完全背包（`dfs(i, ...)` 停在原物品），`combine` 换成 `min`，base 用 `inf` 表示无解。

> [!success]- 递归 + 记忆化
> 
> ```python
> from functools import cache
> from math import inf
> from typing import List
> 
> class Solution:
>     def coinChange(self, coins: List[int], amount: int) -> int:
>         n = len(coins)
> 
>         @cache
>         def dfs(i, c):
>             if i < 0:
>                 return 0 if c == 0 else inf   # 最值：凑不出用 inf
>             if c < coins[i]:
>                 return dfs(i - 1, c)
>             return min(dfs(i - 1, c),         # 不选硬币 i
>                        dfs(i, c - coins[i]) + 1)  # 选：仍停在 i，+1 枚
>         ans = dfs(n - 1, amount)
>         return ans if ans < inf else -1
> ```
> 
> - 与目标和的唯一结构差异：「选」分支是 `dfs(i, ...)` 不是 `dfs(i-1, ...)`，因为硬币能重复用。
> - `combine=min`、base 空集非零时返回 `inf`（求最小时的「不可达」），最后再翻译回 `-1`。

## 从递归到递推：正序与倒序（关键区分）

递推是递归的机械翻译，真正要记牢的是**一维滚动时的遍历方向**——这是 0-1 与完全背包在代码上最容易写错的地方。

> [!tip]- 一维优化：0-1 倒序，完全正序
> 
> 一维数组 `f[c]` 复用同一行。计算 `f[c]` 用到 `f[c-w]`，方向决定 `f[c-w]` 是**旧值**（上一物品）还是**新值**（本物品已更新）：
> 
> | 方向 | `f[c-w]` 取到 | 效果 | 对应 |
> | --- | --- | --- | --- |
> | `c` 从大到小（倒序） | 上一轮旧值 | 物品只用一次 | **0-1 背包** |
> | `c` 从小到大（正序） | 本轮新值 | 物品可重复用 | **完全背包** |
> 
> ```python
> # 0-1 背包（目标和计数）：倒序，且 c 只需到 w[i]
> f = [0] * (target + 1)
> f[0] = 1
> for x in nums:
>     for c in range(target, x - 1, -1):   # ← 倒序
>         f[c] += f[c - x]
> return f[target]
> 
> # 完全背包（零钱兑换求最小）：正序
> f = [inf] * (amount + 1)
> f[0] = 0
> for x in coins:
>     for c in range(x, amount + 1):       # ← 正序
>         f[c] = min(f[c], f[c - x] + 1)
> return f[amount] if f[amount] < inf else -1
> ```
> 
> 记忆锚点：**要「不重复用」就倒着走，把旧值挡在前面；要「重复用」就正着走，让新值滚进来。**

> [!summary]- 递推四层演进（了解即可，理解桥梁）
> 
> 以目标和为例，从二维到一维的机械变形：
> 
> ```python
> # ① 二维：f[i+1][c] 对应 dfs(i, c)，f[0][0]=1 是 base
> f = [[0] * (target + 1) for _ in range(n + 1)]
> f[0][0] = 1
> for i, x in enumerate(nums):
>     for c in range(target + 1):
>         f[i + 1][c] = f[i][c] + (f[i][c - x] if c >= x else 0)
> 
> # ② 滚动数组：只依赖上一行 → 两行 %2 循环使用（纯空间技巧）
> # ③ 一维倒序：连滚动都省掉，见上方 0-1 代码
> ```
> 
> ①→③ 递推式完全相同，只是「谁来存中间结果」。②这类 `%2` 滚动是过渡写法，会看即可，落笔直接写①或③。

## 易错点

> [!warning]- 易错点
> 
> - **0-1 与完全写反**：「选」分支 `dfs(i-1,...)`（用一次）vs `dfs(i,...)`（无限次）；一维时倒序 vs 正序。写反会静默算错，是背包第一坑。
> - **base 返回值张冠李戴**：求方案数空集返回 `1`，求最值返回 `0`（可达）或 `inf`（不可达）。目标和用 1/0，零钱用 0/inf，别混。
> - **目标和的预检查是「恰好」专属**：`target < 0`、`target % 2` 只在恰好语义成立；换成至多/至少要重新审视（至少改成向上取整、删掉整除检查）。
> - **一维遍历下界**：0-1 倒序到 `x-1` 停（`c < x` 无法选），完全正序从 `x` 起；边界少一格就越界或漏算。
> - **查表 vs 边界顺序**：手写 memo 时 base case 必须排在查表前，否则 `dfs(-1)` 静默取到脏值（详见 [[记忆化搜索]]）。

## 复杂度

> [!summary]- 复杂度
> 
> 通用公式：$\text{时间} = \text{状态个数} \times \text{单次转移}$。
> 
> - 状态数 $= n \times C$（物品数 × 容量），单次转移 $O(1)$ ⇒ 时间 $O(nC)$，0-1 与完全同阶。
> - 空间：记忆化 $O(nC)$ + 递归栈；二维递推 $O(nC)$；一维滚动 $O(C)$。
> - 这是**伪多项式**：`C` 是数值大小不是输入长度，`amount` 极大时仍会慢。

## 一句话总结

背包只有一个开关——物品能不能重复用：能→`dfs(i,...)`/一维正序，不能→`dfs(i-1,...)`/一维倒序；其余「最值 vs 计数、恰好 vs 至多 vs 至少」都是在同一骨架上换 `combine` 和 base。

## 模板归纳

拿到一道背包题，按顺序自问：

1. **物品选几次？** 一次→0-1（`dfs(i-1)`/倒序）；无限→完全（`dfs(i)`/正序）。
2. **求什么？** 最值→`combine=max/min`、base 空集 `0`/`inf`；计数→`combine=+`、base 空集 `1`。
3. **约束是恰好/至多/至少？** 只改 base 与容量越界处理（见变体一对照表）。
4. 先写**递归 + `@cache`**（能推导、最稳）；需要压空间再翻**一维**，牢记正序/倒序。

```python
# 背包通用骨架
@cache
def dfs(i, c):
    if i < 0:
        return BASE(c)                       # 计数:1/0；最值:0/inf
    if c < w[i]:
        return dfs(i - 1, c)
    return combine(dfs(i - 1, c),            # 不选
                   dfs(i - 1, c - w[i]))     # 选：0-1 用 i-1，完全用 i
```
