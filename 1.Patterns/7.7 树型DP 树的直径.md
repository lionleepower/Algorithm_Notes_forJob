# 树形 DP：树的直径与「双轨骨架」

## 解决什么问题

题目问的是**树上一条路径**的最值（最长、最大和、最多节点），而这条路径**不保证经过根节点**、也不保证是自上而下的一条链——它可以在某个节点**拐弯**。识别信号：

```text
输入是一棵树 / 无向无环图 + 求某条路径的最值 + 路径可以「拐一次弯」
```

和前面几篇 DP 的分界线要先钉清楚：

| 专题 | 状态是什么 | 子问题从哪来 | 要不要记忆化 |
| --- | --- | --- | --- |
| [[7.1 DP 打家劫舍]]～[[7.6 区间DP 最长回文子序列]] | 下标 / 区间 | 同一个状态被**反复**访问 | **要**，靠 `@cache` 塌缩指数 |
| **本篇 树形 DP** | **树上的一个节点** | 每个节点**只被唯一的父亲调用一次** | **不要**，没有重叠子问题 |

**所以树形 DP 的「DP」在于状态转移（子树的答案怎么合成父节点的答案），不在于缓存。** 它本质是「一次后序 DFS 顺便聚合」——参见 [[重叠子问题与无后效性]]：没有重叠，`@cache` 就没有意义（写了也不会错，只是白占内存）。

## 统一模板：双轨骨架

![](assets/7.7%20树型DP%20双轨骨架.svg)

> [!tip]- 核心思路：为什么必须「一边 return、一边打擂台」
> 
> 本类题真正的结构性难点不是算术，而是这一句：**为什么答案要用 `nonlocal ans` 打擂台，而不是直接 `return`？**
> 
> 因为一次 dfs 里有**两个语义完全不同的量**：
> 
> - **要往上传的**：必须是一条**单链**（从当前节点向下的一条路）。因为父节点还要在它上面再接一条边，接完必须**仍然是一条路径**——所以左右两侧只能挑一条。
> - **要收集的答案**：是一条**拐点路径**（左链 + 当前节点 + 右链）。它在当前节点处**已经分叉成 Y 字形**，父节点没法再往上接（接上去就不是路径了）。
> 
> 所以拐点路径是「**用完即弃**」的，只能当场记进全局擂台；能向上传的只有单链。这也解释了为什么必须**每个节点都当一次拐点试试**——直径不一定经过根节点。
> 
> 这个「**向上传单链、向全局报拐点**」的双轨结构，是一整类树形 DP 的通用骨架，三道例题只是换了「拐点值」和「单链值」两个函数。

> [!success]- 通用骨架
> 
> ```python
> ans = INIT                                  # 全局擂台，初值随题变
>
> def dfs(node):
>     if node is None:
>         return BASE                         # 哨兵，与「拐点值」的写法成套出现
>     l, r = dfs(node.left), dfs(node.right)
>     nonlocal ans
>     ans = max(ans, 拐点值(l, r, node))       # 报答案：允许分叉，用完即弃
>     return 单链值(l, r, node)                # 传上去：必须是一条链
>
> dfs(root)
> return ans
> ```
> 
> - `nonlocal ans`：内层函数要**改写**外层变量必须声明，否则 Python 会把 `ans` 当成新的局部变量并抛 `UnboundLocalError`（只读不写则不需要）——机制见 [[Python_nonlocal与闭包]]。
> - 三道题的差别全在 `BASE`、`INIT`、`拐点值`、`单链值` 这四个空里，**骨架一个字不动**。

## 变体一：543. 二叉树的直径（边数约定）

求二叉树中任意两节点间最长路径的**长度（边数）**。

![](assets/7.7%20树型DP%20两套约定.svg)

> [!tip]- 核心思路：先把合同钉死，`+1` 和 `+2` 就是同一个东西
> 
> $$dfs(node) = \text{以 } node \text{ 为起点向下走到叶子，最长那条链的\textbf{边数}}$$
> 
> **注意是边数，不是节点数——这是全部混乱的源头。**
> 
> 先验证叶子：`l_len` 和 `r_len` 都是 `-1`，返回 `max(-1, -1) + 1`，也就是 `0`。叶子到它自己 0 条边 ✓。
> 
> **所以 `return -1` 不是拍脑袋定的**，它是被「叶子必须返回 0」反推出来的哨兵：空儿子返回 $-1$，加上那条本不存在的边 $+1$，恰好抵消成 $0$。
> 
> 接着，**所有的 `+1` 都在数同一样东西：把 `node` 和它儿子连起来的那条「连接边」**。
> 
> - `return max(l_len, r_len) + 1`：向上传的是「从 `node` 出发的最长下行链」= 儿子那边最长的链 + `node` 到那个儿子的**一条边** ⇒ `+1`。
> - `ans = max(ans, l_len + r_len + 2)`：以 `node` 为拐点的路径 = 左链边数 + **左连接边** + 右链边数 + **右连接边** ⇒ `+2`。
> 
> 一句话：**`return` 那行只往上接一个方向所以 `+1`；`ans` 那行左右两个方向都要接上所以 `+2`。**

> [!example]- 验证两个最小情形
> 
> ```text
> 单个孤立节点：  l_len = r_len = -1
>                 ans = -1 + (-1) + 2 = 0        直径 0 条边 ✓
>
> 一个节点带一个左儿子： l_len = 0, r_len = -1
>                 ans = 0 + (-1) + 2 = 1         一条边 ✓
> ```
> 
> 哨兵 `-1` 在这两个例子里各干了一次活：把不存在的那一侧「减掉」它凭空多算的连接边。

> [!success]- 三种等价写法
> 
> ```python
> # ① 边数约定（原稿写法）
> class Solution:
>     def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
>         ans = 0
>         def dfs(node):
>             if node is None:
>                 return -1                       # 哨兵：抵消虚边
>             l_len = dfs(node.left)
>             r_len = dfs(node.right)
>             nonlocal ans
>             ans = max(ans, l_len + r_len + 2)   # 拐点：左右各一条连接边
>             return max(l_len, r_len) + 1        # 单链：只接一个方向
>         dfs(root)
>         return ans
>
> # ② 同一约定，把 +1 提到接收处（可读性更好，完全等价）
>         def dfs(node):
>             if node is None:
>                 return -1
>             l_len = dfs(node.left) + 1          # 连接边就地加上
>             r_len = dfs(node.right) + 1
>             nonlocal ans
>             ans = max(ans, l_len + r_len)       # 于是这里不用 +2 了
>             return max(l_len, r_len)
>
> # ③ 节点数约定：换个哨兵，+2 直接消失
>         def dfs(node):
>             if node is None:
>                 return 0                        # 空子树有 0 个节点
>             l, r = dfs(node.left), dfs(node.right)
>             nonlocal ans
>             ans = max(ans, l + r)               # 不用 +2
>             return max(l, r) + 1
> ```
> 
> - **三版答案完全一致，都是边数。** 第三版为什么不用加？因为「左边有 `l` 个节点」就意味着「从 `node` 往左有 `l` 条边」——**节点数天然自带了那条连接边**。
> - 这反过来证明 `+2` 不是本质，而是「返回边数 + 空返回 `-1`」这套约定的副产品。
> - `ans` 初值取 `0` 是对的：边数天然非负，单节点树的直径就是 0。

> [!warning]- 两套约定绝不能混
> 
> 最经典的 bug：写了 `return -1`（边数版）却写成 `ans = max(ans, l + r)`（节点数版的公式），答案**恒偏小 2**；反过来写 `return 0` 配 `l + r + 2`，**恒偏大 2**。两种都不报错，只会给你一个稳定错位的答案。
> 
> 记法：**空节点返回 `-1` ⇔ 拐点要 `+2`；空节点返回 `0` ⇔ 拐点不加。** 这是成套的，**一改就得两处一起改**。

## 变体二：124. 二叉树中的最大路径和（clamp 弃权）

路径上节点值之和最大，节点值可以为负，路径至少含一个节点。

> [!tip]- 核心思路：返回的不是「链长」，是「贡献值」
> 
> $$dfs(node) = \text{从 } node \text{ 出发向下走的最大链和，若为负则记作 } 0$$
> 
> **后半句是这题的全部精髓。** 注意 `max(..., 0)` 写在 **`return` 里**，不是写在 `ans` 那行——这意味着向上传的已经不是「真实的最大链和」，而是「**我这棵子树能给父节点做的最大贡献**」。贡献可以是 0，含义是：**「我这边全是负的，你别接我，当我不存在。」**
> 
> 于是 `if node is None: return 0` 不再是哨兵技巧，它和 `max(..., 0)` 是**同一个语义的两处体现**——空子树没东西可拿，贡献 0；负子树主动弃权，贡献也是 0。这就是本题空节点返回 `0` 而不是 543 里 `-1` 的原因。
> 
> **`ans` 那行为什么一个式子就够？** 拐点路径本该有四种形态，但 `l_val`、`r_val` 已被 clamp 到 $\ge 0$：
> 
> | 想表达的形态 | 靠什么自动实现 |
> | --- | --- |
> | 左右都要 | `l_val` 与 `r_val` 都为正，都加上 |
> | 只要左 | `r_val` 恰好是 0，加了等于没加 |
> | 只要右 | `l_val` 是 0 |
> | 只要 node 自己 | 两个都是 0 |
> 
> **clamp 把「要不要」的分类讨论，变成了「加一个可能为 0 的数」。** 四种情况被一个加法吃掉——这是本题最漂亮的地方。反过来说，去掉 `max(..., 0)` 就必须在 `ans` 那行手写四路 `max`，还得给空节点找一个 `-inf` 哨兵，代码立刻变丑。

> [!tip]- `node.val` 为什么不参与 clamp
> 
> ```python
> return max(max(l_val, r_val) + node.val, 0)
> #                              ↑ node.val 在里面，看似被一起 clamp 了
> ```
> 
> 语义上要分两层看：
> 
> - **在 `return` 里**：clamp 的对象是「node 这条链**整体**」。若 node 自己是 $-10$、儿子贡献 $3$，整条链是 $-7$，父节点接上去只会亏，所以整体弃权返回 0 ✓
> - **在 `ans` 里**：`node.val` **裸着加**，没有 clamp。因为路径**至少包含一个节点**，node 作为拐点是被钦定的，**不能弃权**。
> 
> 一句话：**弃权只针对子树，不针对自己。**

> [!success]- 代码实现
> 
> ```python
> from math import inf
>
> class Solution:
>     def maxPathSum(self, root: Optional[TreeNode]) -> int:
>         ans = -inf                                    # 不能写 0
>         def dfs(node):
>             if node is None:
>                 return 0                              # 空子树贡献 0
>             l_val = dfs(node.left)
>             r_val = dfs(node.right)
>             nonlocal ans
>             ans = max(ans, l_val + r_val + node.val)  # 拐点：node.val 裸加
>             return max(max(l_val, r_val) + node.val, 0)   # 单链：整体可弃权
>         dfs(root)
>         return ans
> ```
> 
> - **关键变量**：`l_val` / `r_val` 是「子树的贡献」而非「子树的最大链和」，两者只在负数时不同。
> - **易错位置**：`ans` 初值、`return` 的 clamp、空节点返回值——三者必须成套。

> [!warning]- 两个初始化陷阱
> 
> **① `ans = -inf` 不能写成 `ans = 0`。** 若树全是负数，比如 `[-3]`，答案就是 $-3$（路径不能为空），初始化成 0 会返回 0。对照 543：那题 `ans = 0` 是对的，因为边数天然非负。**这两题的初值不能互抄。**
> 
> **② `max(..., 0)` 和 `return 0` 必须成套出现。** 最小反例，树 `[2, -1]`（根 2，左儿子 -1）：
> 
> ```text
> 正确答案：2（只取根节点）
>
> clamp 版：
>   dfs(-1) → ans = max(-inf, 0+0-1) = -1，return max(-1, 0) = 0
>   dfs(2)  → ans = max(-1, 0+0+2)   = 2        ✓
>
> 不 clamp 但空节点仍返回 0：
>   dfs(-1) → return 0 + (-1) = -1
>   dfs(2)  → ans = max(..., -1+0+2) = 1        ✗ 被负儿子拖累
> ```

## 变体三：2246. 相邻字符不同的最长路径（多叉树 + 滚动配对）

给一棵以 `parent` 数组描述的树和字符串 `s`，求一条路径，使路径上**相邻两点字符都不同**，返回其**节点数**。

![](assets/7.7%20树型DP%20滚动配对.svg)

> [!tip]- 核心思路：边遍历边打擂台，一次拿到最大两条链
> 
> $$dfs(x) = \text{从 } x \text{ 出发向下走、且相邻字符都不同的最长链的\textbf{边数}}$$
> 
> 回到 543 的**边数**约定。二叉树只有左右两个儿子，拐点直接 `l + r` 就行；多叉树有 $k$ 个儿子，拐点要挑**最大的两条链**——这份代码用一次遍历同时完成「找最大两个」和「打擂台」，不用排序。
> 
> **不变量是关键**：
> 
> > 处理第 $k$ 个儿子时，`x_len` 恰好是**前 $k-1$ 个儿子中最长的那条链**。
> 
> 于是 `x_len + y_len` 的含义是「**历史最优 + 当前这个**」。
> 
> **为什么遍历完就一定拿到了最大两个之和？** 设全局最长的两条链来自儿子 $p$ 和 $q$（$p < q$）。处理到 $q$ 时，$p$ 必然是前 $q-1$ 个里最长的（否则 $p$ 就不是全局第二了），即 `x_len` 此刻正好等于 $p$ 的链长，**那一轮算出的就是答案**。其余轮次算的都是更小的组合，被 `max` 自然滤掉。
> 
> 这个「**维护前缀最大值 + 当场配对**」的写法，是所有多叉树版拐点问题的标准手法，值得单独记住。

> [!success]- 代码实现（两版：只存 children / 存双向边）
> 
> ```python
> # ① g 只存 children，不需要 fa 参数
> class Solution:
>     def longestPath(self, parent: List[int], s: str) -> int:
>         n = len(parent)
>         g = [[] for _ in range(n)]
>         for i in range(1, n):                   # 必须从 1 开始，parent[0] 是 -1
>             g[parent[i]].append(i)
>
>         ans = 0
>         def dfs(x):
>             nonlocal ans
>             x_len = 0                           # 初值 0 恰好是叶子的正确语义
>             for y in g[x]:
>                 y_len = dfs(y) + 1              # 递归无条件执行
>                 if s[y] != s[x]:
>                     ans = max(ans, x_len + y_len)   # ① 先用旧值配对
>                     x_len = max(x_len, y_len)       # ② 再让新值入库
>             return x_len
>         dfs(0)
>         return ans + 1                          # 边数 → 节点数
>
> # ② 若题目给的是无向边列表，g 存双向边，就必须传 fa 防回头
>         def dfs(x, fa):
>             nonlocal ans
>             x_len = 0
>             for y in g[x]:
>                 if y == fa: continue
>                 y_len = dfs(y, x) + 1
>                 if s[y] != s[x]:
>                     ans = max(ans, x_len + y_len)
>                     x_len = max(x_len, y_len)
>             return x_len
>         dfs(0, -1)
> ```
> 
> - **`+1` 出现在两个地方，含义完全不同**：`y_len = dfs(y) + 1` 是**连接边**（等价于 543 里 `return ... + 1` 的那个 `+1`）；`return ans + 1` 是**单位换算**（`ans` 数的是边，题目要节点数，$k$ 条边对应 $k+1$ 个节点）。
> - 验证单节点树 `parent = [-1]`、`s = "a"`：`dfs(0)` 循环为空，`ans` 保持 0，返回 `0 + 1 = 1` ✓

> [!warning]- 这题的三个坑
> 
> **① 顺序陷阱：`ans` 那行和 `x_len` 那行绝对不能交换。**
> 若先更新 `x_len` 再配对，当 `y_len` 是目前最大时 `x_len` 已被更新成 `y_len`，下一行算出 `y_len + y_len`——**同一个儿子被当成两条链用了两次**，答案偏大。用不变量的语言说：`x_len` 必须在「**尚未包含当前 `y`**」的状态下参与配对。（这和 [[7.3 线性dp 最长公共子序列]] 一维滚动里 `pre` 的三步顺序是同一类错误：**旧值必须在被覆盖前用掉**。）
> 
> **② `if s[y] != s[x]` 只能包住那两行，绝不能包住递归。**
> `dfs(y)` 必须无条件执行，因为它除了返回链长还有一个**副作用**——把 **y 子树内部的最优拐点路径**记进 `ans`，那些路径压根不经过 `x`，跟 `s[x]` 是什么毫无关系。把递归挪进 `if` 里，整棵子树就不会被访问，里面的答案全丢。
> **递归是为了「跑遍全树」，`if` 是为了「决定这条链能不能用」，两层职责不同。**
> 
> **③ 建图必须 `for i in range(1, n)`。**
> `parent[0]` 是 `-1`，从 `i = 0` 开始会执行 `g[-1].append(0)`——Python 的负下标**不报错**，会把节点 0 挂到 `g[n-1]` 底下，**凭空造出一条环**，`dfs` 立刻无限递归。和 [[7.1 DP 打家劫舍]] 里 `memo[-1]` 静默取值是同一个坑：**Python 的负下标只会安静地给你错误答案。**

> [!tip]- 为什么这题不用写 base case
> 
> 叶子不需要 `if not g[x]: return 0`，因为 `x_len` 的初值 `0` **恰好就是叶子的正确语义**（`for` 一次都不进，直接返回 0）。
> 
> 对照 [[7.6 区间DP 最长回文子序列]] 里的 1039：那题 `res` 初值是 `inf`，空循环会把哨兵原样漏出去，所以**必须**显式写 base。
> 
> **判据是「初值是否等于边界的语义值」，不是「有没有循环」。** 这两题正好是一组正反例。

## 三题对照（套模板时看这张表）

> [!summary]- 543 vs 124 vs 2246：什么不变、什么改变
> 
> **完全不变**：双轨骨架、「拐点用完即弃 / 单链才能上传」的理由、一次后序 DFS、不需要 `@cache`、$O(n)$ 时间。
> 
> **改变的只有四个空**：
> 
> | | 543. 直径 | 124. 最大路径和 | 2246. 最长合法路径 |
> | --- | --- | --- | --- |
> | 树形态 | 二叉 | 二叉 | **多叉** |
> | 返回值语义 | 最长下行链的**边数** | 最大下行链的**和**（负则记 0） | 最长**合法**下行链的边数 |
> | 空 / 叶子 | `None` → `-1`（哨兵） | `None` → `0`（真实语义） | 空循环 → `0`（初值即语义） |
> | 拐点值 | `l + r + 2` | `l_val + r_val + node.val` | **`x_len + y_len` 滚动配对** |
> | 单链值 | `max(l, r) + 1` | `max(max(l,r) + node.val, 0)` | `max(x_len, y_len)` |
> | `ans` 初值 | `0`（边数非负） | `-inf`（值可负） | `0` |
> | 过滤 / 弃权 | 无 | `max(..., 0)` 弃权 | `s[y] != s[x]` 过滤 |
> | 最终换算 | 直接返回 | 直接返回 | `ans + 1`（边 → 点） |
> 
> **多叉相对二叉的唯一变化，就是拐点值从「一次相加」变成「滚动配对」。**

## 易错点

> [!warning]- 易错点
> 
> - **哨兵与拐点公式混用**：`return -1` 必须配 `l + r + 2`，`return 0` 必须配 `l + r`。混着写答案恒偏差 2，不报错。
> - **`ans` 初值抄错**：边数 / 长度类用 `0`；**带负值的求和类必须用 `-inf`**，否则全负树返回 0。
> - **124 忘了 clamp 或只 clamp 一半**：`max(..., 0)` 与 `return 0` 成套；`ans` 那行的 `node.val` 不参与 clamp（拐点不能弃权）。
> - **多叉树先更新后配对**：`x_len` 必须以旧值参与配对，否则同一个儿子被用两次。
> - **把递归写进条件分支里**：`dfs(y)` 必须无条件跑，它承担「遍历全树、收集子树内部答案」的副作用。
> - **负下标建图**：`for i in range(1, n)`，`g[parent[0]]` 就是 `g[-1]`，会造环导致无限递归。
> - **直接 `return` 拐点值**：拐点路径是 Y 字形，父节点接不上去。**只有单链能上传**——这是本类题的根本约束。
> - **多此一举加 `@cache`**：树上每个节点只被唯一父亲调用一次，**没有重叠子问题**（对比 [[记忆化搜索]] 的适用场景）。
> - **递归深度**：$n$ 可达 $10^5$，链状树会触发 Python 默认递归上限 1000。面试白板时值得主动提一句「必要时改迭代或 `sys.setrecursionlimit`」。

## 复杂度

> [!summary]- 复杂度
> 
> 三题同阶，因为骨架相同：
> 
> - **时间 $O(n)$** —— 每个节点恰好被访问一次、每条边恰好被走一次；多叉树版的内层 `for` 累计起来正好是总边数 $n-1$，**不是** $O(nk)$。
> - **空间 $O(h)$** —— 递归栈深度等于树高；最坏情况（链状树）退化为 $O(n)$，平衡树为 $O(\log n)$。
> - 2246 额外有邻接表 $O(n)$。
> - **没有记忆化开销**：树形 DP 不存在重叠子问题，不需要 `@cache` 的哈希表空间——这是它和前六篇 DP 最大的实现差异。

## 一句话总结

树形 DP 的骨架永远是**双轨**——**向全局报「拐点值」（允许分叉，用完即弃），向父节点传「单链值」（必须还是一条链）**；剩下的全是约定问题：哨兵 `-1` 配拐点 `+2`、clamp 让负子树弃权、多叉树用「先配对再更新」的滚动擂台拿最大两条链。

## 模板归纳

看到「**一棵树** + 求一条**路径**的最值 + 路径可以拐弯 / 不保证过根」，四步落笔：

1. **先想双轨**：这一趟 dfs 要**报**什么（拐点值，可以分叉）、要**传**什么（单链值，必须是链）。想不清这两个量的区别，后面全乱。
2. **写合同**：`dfs(node) = 从 node 向下的最长/最大单链`，并**当场确定单位**——边数还是节点数？和还是长度？单位定了，哨兵和 `+1` 就都定了。
3. **验叶子**：把叶子代进去，看返回值是不是正确语义。**哨兵是被这一步反推出来的**，不是背的（`-1` 抵消虚边、`0` 表示空贡献、`x_len = 0` 表示叶子无链）。
4. **定 `ans` 初值**：非负量用 `0`；可能为负的求和量用 `-inf`。多叉树把「一次相加」换成「**先配对、再更新**」的滚动擂台。

```python
# 树形 DP 通用骨架
ans = INIT                                  # 非负量 0；可为负的求和量 -inf

def dfs(node):
    if node is None:
        return BASE                         # 边数版 -1；求和版 0
    l, r = dfs(node.left), dfs(node.right)  # 多叉：for y in g[x]，滚动配对
    nonlocal ans
    ans = max(ans, 拐点值(l, r, node))       # 报答案：允许分叉，用完即弃
    return 单链值(l, r, node)                # 传上去：必须是一条链

dfs(root)
return ans
```
