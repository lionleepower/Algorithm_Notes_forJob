# 207 / 210. 课程表：拓扑排序与判环

## 题目

`n` 门课，`prerequisites[i] = [a, b]` 表示「学 `a` 前必须先学 `b`」。
207 问**能否修完所有课**；210 要求**给出一个可行的学习顺序**。

## 思路

「A 必须在 B 之前」= 有向边 $B \to A$。这类约束排序问题的标准解法是**拓扑排序 Topological Sort**；能排完 $\iff$ 图中**无环**。

识别信号：

```text
「依赖 / 先修 / 前置条件」+「排出一个顺序」或「判断是否可行」
```

> [!tip]- 核心思路：入度为 0 才能出场，出不完就是有环
>
> **建图方向是第一个坑。** `[a, b]` 读作「b 是 a 的先修」，所以边是 $b \to a$（先修指向后修），`a` 的**入度**加一。入度(indeg) = 还欠着几门没修。
>
> **BFS 写法（Kahn 算法）**
>
> 1. 所有**入度为 0** 的点入队——它们不欠任何前置，随时可以学。
> 2. 每弹出一个点 `u`，把它「学完」，于是它的所有后继 `v` 少欠一门：`indeg[v] -= 1`；减到 0 就入队。
> 3. 队空时统计出队总数。
>
> **为什么能判环**：环上的每个点都至少欠环里的另一个点一门，入度**永远降不到 0**，所以永远进不了队。于是
>
> $$\text{出队总数} = n \iff \text{无环} \iff \text{能修完}$$
>
> 这里的队列语义和 [[9.0 图论 网格DFS与多源BFS]] 的多源 BFS 完全一致：**初始所有入度 0 的点 = 多个源点**；差别只是「能否入队」的条件从「格子是新鲜的」换成「入度归零」。
>
> **DFS 写法（三色标记）**：`0` 未访问、`1` 访问中（在当前递归栈上）、`2` 已完成。若 DFS 撞上状态为 `1` 的点，说明沿着当前路径绕回来了，**存在环**。逆后序即拓扑序。
> 两种写法都要会，但**面试首推 BFS**：不会爆栈，且天然产出顺序。

> [!example]- 示例推演：`n = 4`，`prerequisites = [[1,0],[2,0],[3,1],[3,2]]`
>
> ```text
> 建图： 0 -> 1, 0 -> 2, 1 -> 3, 2 -> 3
> 入度： [0, 1, 1, 2]（看的是多少个去指向它）
>
> 初始 q = [0]                     order = []
> 弹 0 -> indeg[1]=0 入队, indeg[2]=0 入队    order = [0]      q = [1,2]
> 弹 1 -> indeg[3]=1                          order = [0,1]    q = [2]
> 弹 2 -> indeg[3]=0 入队                     order = [0,1,2]  q = [3]
> 弹 3                                        order = [0,1,2,3]
>
> len(order) == 4 == n  -> 可以修完
> ```
>
> 若再加一条 `[0,3]`（0 依赖 3），入度变成 `[1,1,1,2]`，**初始队列为空**，一个都出不来，`len(order) = 0 < 4`，判定有环。

## 代码实现

> [!success]- BFS（Kahn）实现：一份代码同时解 207 和 210
>
> ```python
> from collections import deque
>
> class Solution:
>     def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
>         g = [[] for _ in range(numCourses)]      # g[b] = 学完 b 之后解锁的课
>         indeg = [0] * numCourses
>         for a, b in prerequisites:               # [a, b]：先 b 后 a
>             g[b].append(a)                       # 边 b -> a
>             indeg[a] += 1
>
>         q = deque(i for i in range(numCourses) if indeg[i] == 0)
>         order = []
>         while q:
>             u = q.popleft()
>             order.append(u)
>             for v in g[u]:
>                 indeg[v] -= 1
>                 if indeg[v] == 0:                # 只在归零那一刻入队，保证不重复
>                     q.append(v)
>
>         return order if len(order) == numCourses else []
>         # 207 只需：return len(order) == numCourses
> ```
>
> **主流程**：建图 + 统计入度 $\to$ 入度 0 全部入队 $\to$ 弹一个减一圈 $\to$ 比对出队数。
>
> **关键变量**
> - `g[u]`：`u` 的**后继**（学完 `u` 才解锁的课）
> - `indeg[v]`：`v` 还欠几门先修
> - `order`：拓扑序；它的长度就是判环依据
>
> **易错位置**：建图方向、以及 `if indeg[v] == 0` 必须是**等于 0** 而不是 `<= 0`（虽然等价，但写成 `< 1` 之类容易在多重边时重复入队）。

> [!success]- DFS 三色标记（判环写法）
>
> ```python
> class Solution:
>     def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
>         g = [[] for _ in range(numCourses)]
>         for a, b in prerequisites:
>             g[b].append(a)
>         color = [0] * numCourses                 # 0 未访问 / 1 访问中 / 2 已完成
>
>         def dfs(u: int) -> bool:                 # 返回 True 表示发现环
>             color[u] = 1
>             for v in g[u]:
>                 if color[v] == 1:                # 撞上「当前栈上」的点 -> 有环
>                     return True
>                 if color[v] == 0 and dfs(v):
>                     return True
>             color[u] = 2                         # 整棵子树都走完了，永久安全
>             return False
>
>         return not any(color[u] == 0 and dfs(u) for u in range(numCourses))
> ```
>
> **为什么必须三色而不是两色**：只用 `visited` 布尔值，无法区分「在当前路径上（成环）」和「以前走过且已确认安全（无环）」。把后者也判成环会**误报**。
> `color = 1` 的含义正是 [[6.0 回溯型算法]] 里「在当前路径上」，`color = 2` 则是永久标记——一个点身上同时存在两种标记语义，这是本题最值得说的一句。

## 易错点

> [!warning]- 易错点
>
> **1. 建图方向反了**
> 把 `[a, b]` 建成 $a \to b$、给 `b` 加入度，得到的是**逆拓扑序**。207 判环仍然对（反图有环等价于原图有环），210 会输出倒序而 WA——这让错误极难定位。
> **记忆法**：`[a, b]` 读成「a 依赖 b」，箭头永远从**被依赖者**指向**依赖者**，入度加在**依赖者**身上。
>
> **2. 用 `visited` 集合代替入度归零**
> 一个点有多个先修时会被提前放行，输出的顺序违反依赖。**入队条件只有一个：入度归零。**
>
> **3. 忘记判环就直接返回 `order`**
> 210 在有环时必须返回 `[]`，不是返回残缺的部分序。
>
> **4. DFS 只用两色**
> 会把「已确认安全的旧路径」误判为环，答案偏假。必须区分 `1` 和 `2`。
>
> **5. 自环与重边**
> `[a, a]` 是自环，入度永远 $\ge 1$，Kahn 天然判死；重边会让入度多加，也天然正确——**不需要去重**。
>
> **6. 递归深度**
> DFS 写法在链状依赖（$n = 10^5$）时会爆栈。BFS 无此问题，这是面试推荐 BFS 的实际理由。

## 复杂度

> [!summary]- 复杂度
>
> - 时间：$O(V + E)$ —— 每个点恰好入队出队一次，每条边在「减入度」时恰好被遍历一次。
> - 空间：$O(V + E)$ —— 邻接表 $O(E)$，入度数组与队列 $O(V)$。
>
> 对比暴力「反复扫描找可修课」的 $O(V^2)$：省下的是「每轮重新检查所有点」，入度数组把这个检查摊成了 $O(1)$。

## 一句话总结

拓扑排序 = **多源 BFS，只是入队条件从「相邻」换成「入度归零」**；出队数少于 $n$ 就是有环——因为环上的点永远等不到自己的最后一门先修。

## 模板归纳

**触发信号 $\to$ 条件反射**

- 「先修 / 依赖 / 必须在……之前」$\to$ 有向图 + 拓扑排序
- 「能否完成 / 是否存在合法顺序」$\to$ 判环，看出队数是否等于 $n$
- 「输出任意一个可行顺序」$\to$ Kahn 的 `order` 直接就是答案

**落笔五步**

1. **定方向**：被依赖者 $\to$ 依赖者，入度加在依赖者身上。
2. 建 `g` 与 `indeg`，一次循环搞定。
3. `indeg == 0` 的点全部入初始队列（**这是多源**）。
4. 弹点、减后继入度、归零即入队。
5. `len(order) == n` 判环，再决定返回什么。

**自检一问**：如果整张图是一个环，我的初始队列是空的吗？空的 $\to$ 方向和入度都建对了。
