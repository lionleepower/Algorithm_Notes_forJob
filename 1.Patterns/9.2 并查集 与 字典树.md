# 并查集与字典树：两个「要背下来」的结构

## 解决什么问题

这两个结构都属于**写出来就赢一半**的类型——思路不难，难在手写不出错。

| 结构 | 回答什么问题 | 代表题 |
| --- | --- | --- |
| **并查集 Union-Find** | 「这两个东西现在是不是一伙的」+ **动态合并** | 200. 岛屿数量、547. 省份数量、684. 冗余连接 |
| **字典树 Trie** | 「有没有以某段前缀开头的串」 | 208. 实现 Trie、211. 添加与搜索单词 |

选型判据：
- 只需一次性遍历静态图 $\to$ **DFS/BFS 就够**（[[9.0 图论 网格DFS与多源BFS]]）
- 边**边加边问**连通性 / 需要判无向图的环 $\to$ **并查集**
- 反复按**前缀**查询一堆字符串 $\to$ **Trie**（哈希表能查完整串，查不了前缀）

## 并查集

> [!tip]- 核心思路：每个集合选一个代表，问「同不同伙」就是问「代表是不是同一个」
>
> **两个操作**
> - `find(x)`：一路顺着 `fa` 往上爬，找到集合的代表（根）。
> - `union(x, y)`：把两个根接起来，两个集合合并成一个。
>
> **两个优化，缺一个就退化成 $O(n)$**
>
> **1. 路径压缩（Path Compression）**：`find` 回程时把沿途所有节点直接挂到根上。下一次查询就是 $O(1)$。
> 树高被压平——并查集**从来不关心树的形状**，只关心根是谁，所以随便压。
>
> **2. 按秩/按大小合并（Union by Size）**：总把**小树挂到大树**下面，避免链化。
>
> 两个都用时，单次操作的均摊复杂度是 $O(\alpha(n))$（$\alpha$ 是反阿克曼函数，现实中 $\le 4$），可以当常数看。
>
> **判环**：`union(x, y)` 时若发现 `find(x) == find(y)`，说明这条边连接的两点**本来就连通**，加上它就成环——684 冗余连接就是这一条。

> [!success]- 模板代码（背下来）
>
> ```python
> class UnionFind:
>     def __init__(self, n: int):
>         self.fa = list(range(n))     # 初始每个点自成一集，代表是自己
>         self.size = [1] * n          # 各集合大小（按大小合并用）
>         self.cnt = n                 # 连通块个数，合并成功才减一
>
>     def find(self, x: int) -> int:
>         if self.fa[x] != x:
>             self.fa[x] = self.find(self.fa[x])   # 路径压缩：回程直接挂到根
>         return self.fa[x]
>
>     def union(self, x: int, y: int) -> bool:
>         fx, fy = self.find(x), self.find(y)
>         if fx == fy:
>             return False             # 已同集：这条边会成环
>         if self.size[fx] < self.size[fy]:
>             fx, fy = fy, fx          # 保证 fx 是大树
>         self.fa[fy] = fx
>         self.size[fx] += self.size[fy]
>         self.cnt -= 1
>         return True
> ```
>
> **关键变量**
> - `fa[x]`：`x` 的父节点；`fa[x] == x` 表示 `x` 是根
> - `cnt`：连通块个数，很多题的答案直接就是它
> - `union` 的返回值：`False` 表示**发现环**，别丢掉这个信息
>
> **易错位置**：`union` 里必须先 `find` 再赋值——写成 `self.fa[y] = x`（接的是点而不是根）会直接把已有结构拆散。

> [!example]- 用并查集做 200. 岛屿数量
>
> 把二维坐标压成一维编号 `id = i * n + j`，只需向**右**和**下**合并（向左和上是重复的）：
>
> ```python
> def numIslands(self, grid: List[List[str]]) -> int:
>     m, n = len(grid), len(grid[0])
>     uf = UnionFind(m * n)
>     water = 0
>     for i in range(m):
>         for j in range(n):
>             if grid[i][j] == '0':
>                 water += 1
>                 continue
>             if i + 1 < m and grid[i + 1][j] == '1':
>                 uf.union(i * n + j, (i + 1) * n + j)
>             if j + 1 < n and grid[i][j + 1] == '1':
>                 uf.union(i * n + j, i * n + j + 1)
>     return uf.cnt - water        # 每个水格也算一个"块"，要减掉
> ```
>
> **`- water` 是本写法最大的坑**：`UnionFind(m*n)` 把水格也初始化成了独立集合。
> 结论：**200 用 DFS 更短更不易错；并查集的价值在于「边是动态加进来的」场景**，比如 684、721。面试可以主动说这句对比。

## 字典树 Trie

> [!tip]- 核心思路：把公共前缀合并成同一条路径
>
> 一棵多叉树，**边代表字符，路径代表前缀**，节点上挂一个 `is_end` 表示「到这里恰好是一个完整单词」。
>
> **为什么哈希表不能替代**：`set` 能 $O(1)$ 回答「`apple` 在不在」，但回答不了「有没有以 `app` 开头的词」——除非枚举所有前缀或所有词。Trie 把这个问题变成**沿着树走 $L$ 步**，与词表大小无关。
>
> **`is_end` 是必需的**：只看「路径能走通」无法区分 `app` 是完整单词还是 `apple` 的前缀。`search` 要求 `is_end == True`，`startsWith` 不要求——两个方法唯一的区别就在这一行。
>
> **两种孩子表示**
> - `children = [None] * 26`：只含小写字母时更快，定长数组直接下标寻址
> - `children = {}`：字符集大或稀疏时省空间，写起来也更短

> [!success]- 208. 实现 Trie（前缀树）
>
> ```python
> class Trie:
>     def __init__(self):
>         self.children = {}          # 字符 -> 子节点（每个节点自己就是一棵子树）
>         self.is_end = False
>
>     def insert(self, word: str) -> None:
>         node = self
>         for ch in word:
>             if ch not in node.children:
>                 node.children[ch] = Trie()
>             node = node.children[ch]
>         node.is_end = True          # 只在词尾打标记
>
>     def _walk(self, s: str):
>         """沿着 s 走，走不通返回 None"""
>         node = self
>         for ch in s:
>             if ch not in node.children:
>                 return None
>             node = node.children[ch]
>         return node
>
>     def search(self, word: str) -> bool:
>         node = self._walk(word)
>         return node is not None and node.is_end     # 必须是完整单词
>
>     def startsWith(self, prefix: str) -> bool:
>         return self._walk(prefix) is not None       # 走得通就行
> ```
>
> **主流程**：`insert` 沿路建点、词尾打标；两个查询共用「沿路走」，只差要不要看 `is_end`。
> **关键不变量**：从根到任一节点的边序列，恰好是某些已插入单词的公共前缀。
> **易错位置**：`search` 漏掉 `node.is_end`，会把「前缀」误判成「单词」——这是 208 唯一的测试点。

## 易错点

> [!warning]- 易错点
>
> **1. 并查集：`union` 时接的是点不是根**
> `self.fa[y] = x` 会把 `y` 原来的整棵子树从它的根上扯下来。必须 `self.fa[fy] = fx`。
>
> **2. 并查集：`find` 写成循环但忘了压缩**
> 能过小数据，大数据退化成 $O(n)$ 每次。递归写法压缩最短，但深度大时要注意栈；迭代写法：
> ```python
> def find(self, x):
>     root = x
>     while self.fa[root] != root:
>         root = self.fa[root]
>     while self.fa[x] != root:            # 第二遍：全部挂到 root
>         self.fa[x], x = root, self.fa[x]
>     return root
> ```
>
> **3. 并查集：把「块数」和「元素数」搞混**
> 200 里没有排除水格就是这一类。**初始化了多少个点，`cnt` 就从多少开始**。
>
> **4. 并查集用在有向图上**
> 它只表达**无向连通性**。207 课程表判的是**有向环**，并查集判不了，必须拓扑排序（[[9.1 拓扑排序 课程表]]）。
>
> **5. Trie：所有节点共用一个 `children` 字典**
> 把 `children` 写成类属性而不是 `__init__` 里的实例属性，所有节点会共享同一个字典，整棵树塌成一个节点。
>
> **6. Trie：`search` 与 `startsWith` 写成同一个**
> 见上文，唯一区别是 `is_end`。
>
> **7. Trie 的空间**
> 最坏 $O(\sum L \times |\Sigma|)$。用定长 26 数组时，$10^4$ 个长 $10$ 的词就是十万级节点、每个 26 槽——面试要能报出这个数量级，并说明字典版更省。

## 复杂度

> [!summary]- 复杂度
>
> **并查集**
> - 时间：单次 `find` / `union` 均摊 $O(\alpha(n))$ ≈ $O(1)$（路径压缩 + 按大小合并两者同时使用）；只用其中一个是 $O(\log n)$，都不用是 $O(n)$。
> - 空间：$O(n)$ —— `fa` 与 `size` 两个数组。
>
> **Trie**（$L$ 为单词长度，$|\Sigma|$ 为字符集大小）
> - 时间：`insert` / `search` / `startsWith` 均为 $O(L)$ —— **与已插入的单词数量无关**，这正是它打败哈希表的地方。
> - 空间：$O(\sum L)$ 个节点（字典版），定长数组版乘以 $|\Sigma|$。

## 一句话总结

并查集把「连通性」压缩成**一个代表元**，所以敢边合并边查询；Trie 把「公共前缀」压缩成**一条共享路径**，所以查询只花单词长度、与词表大小无关。

## 模板归纳

**触发信号 $\to$ 条件反射**

- 「有多少个连通块 / 这两个点连通吗」+ **边是逐条给出的** $\to$ 并查集
- 「加哪条边会成环」$\to$ 并查集，`union` 返回 `False` 的那条
- 「前缀 / 自动补全 / 一堆单词一起查」$\to$ Trie
- 「有向图的先后顺序或环」$\to$ **不是并查集**，去看 [[9.1 拓扑排序 课程表]]

**并查集落笔三步**

1. 抄模板（`fa` / `size` / `cnt` + 路径压缩 + 按大小合并）。
2. 想清楚**编号怎么映射**：二维格子 `i*n+j`、字符串用 `dict` 映射到整数。
3. 答案是 `cnt` 还是 `union` 的返回值？**先想清楚再写循环。**

**Trie 落笔三步**

1. 节点 = `children` + `is_end`，两者都在 `__init__` 里。
2. 抽一个「沿路走」的私有方法，三个 API 都复用它。
3. `search` 看 `is_end`，`startsWith` 不看——写完立刻用 `insert("apple")` + `search("app")` 自测。
