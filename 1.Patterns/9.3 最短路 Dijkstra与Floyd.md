# 最短路：Dijkstra 与 Floyd

## 解决什么问题

[[9.0 图论 网格DFS与多源BFS]] 里的 BFS 已经能求最短路，但它有一个隐含前提：**每条边的代价都是 1**，所以「按层出队」等价于「按距离递增出队」。

一旦边有了不同的权重，层数就不再等于距离，BFS 失效。补上这一块，最短路的四件套就齐了：

| 算法 | 适用 | 复杂度 | 一句话内核 |
| --- | --- | --- | --- |
| **BFS** | 边权**全为 1** | $O(V+E)$ | 按层出队 |
| **Dijkstra** | 边权**非负**，单源 | $O(E\log V)$ 堆优化 | 每次确定「当前最近的未确定点」 |
| **Bellman-Ford / SPFA** | 允许**负权边**，单源 | $O(VE)$ | 松弛 $V-1$ 轮，第 $V$ 轮还能松弛 ⇒ 有负环 |
| **Floyd** | 任意边权（无负环），**多源** | $O(V^3)$ | 逐个放开中转点的区间 DP |

识别信号：

```text
「从 X 到 Y 的最小代价」+ 边权不全相同        →  Dijkstra
「任意两点之间」+ 点数 n ≤ 400 左右           →  Floyd
「有负权 / 要判负环」                        →  Bellman-Ford
「边权只有 0 和 1」                          →  0-1 BFS（双端队列）
```

## 典型变体

### 变体一：743. 网络延迟时间（Dijkstra 堆优化模板）

![](assets/9.3%20Dijkstra%20确定顺序与负权.svg)

> [!tip]- 核心思路：一个「只增不减」的确定集合
>
> 维护 `dis[]` 表示当前已知的最短距离估计。每一轮，**从还没确定的点里挑出 `dis` 最小的那个，宣布它已经是最终答案**，然后用它去松弛邻居。
>
> **为什么这个贪心是对的**：设当前最小的是 `x`。任何绕开 `x` 的其他路径都必须先走到某个还没确定的点 `y`，而 `dis[y] >= dis[x]`，再加上一条**非负**边只会更远。所以 `dis[x]` 不可能再被改小。
>
> **前提是边权非负**。有一条负边就崩：`0→1 (2)`、`0→2 (5)`、`2→1 (−4)` 里，Dijkstra 会先封存 `dis[1] = 2`，而真实答案是 $5-4=1$。这是面试里最爱追问的一条，务必能当场举出这个反例。
>
> **朴素实现**每轮扫一遍找最小值，$O(V^2)$；用最小堆代替这次扫描就是**堆优化**，$O(E\log V)$。稠密图（$E \approx V^2$）用朴素反而更快。

> [!success]- 代码实现（堆优化，背这一份）
>
> ```python
> from heapq import heappush, heappop
> from math import inf
>
> class Solution:
>     def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
>         g = [[] for _ in range(n + 1)]           # 邻接表：g[u] = [(v, w), ...]
>         for u, v, w in times:
>             g[u].append((v, w))
>
>         dis = [inf] * (n + 1)
>         dis[k] = 0
>         h = [(0, k)]                             # (距离, 点)，距离放前面才能按它排序
>         while h:
>             d, x = heappop(h)
>             if d > dis[x]:                       # 过期项：x 早就被更短的路径确定过
>                 continue
>             for y, w in g[x]:
>                 nd = d + w
>                 if nd < dis[y]:                  # 松弛成功才入堆
>                     dis[y] = nd
>                     heappush(h, (nd, y))
>
>         ans = max(dis[1:])
>         return ans if ans < inf else -1
> ```
>
> - **`if d > dis[x]: continue` 不能省**。堆里允许同一个点存在多个条目（每次松弛成功都会 push 一个），弹出时必须跳过已经过期的旧条目，否则会拿一个偏大的距离去做无效松弛。这叫**懒删除**——比实现「堆内 decrease-key」简单得多，是竞赛和面试的标准写法。
> - 堆里的元组必须是 `(距离, 点)`，把距离放第一位，Python 的元组比较才会按距离排序。
> - 起点不必特判：`dis[k] = 0` 加上入堆即可。

### 变体二：1631. 最小体力消耗路径（Dijkstra 的变形）

从左上走到右下，一条路径的代价定义为**路径上相邻格子高度差的最大值**，求最小代价。

> [!tip]- 核心思路：Dijkstra 不要求代价必须是「求和」
>
> Dijkstra 真正需要的性质只有一条：**路径变长时代价单调不减**（这样才有「已确定就不再变」）。求和满足，取最大值同样满足。
>
> 所以整个模板一字不改，只把松弛那一行的 `d + w` 换成 `max(d, w)`：
>
> ```python
> nd = max(d, abs(heights[nx][ny] - heights[x][y]))
> ```
>
> `dis[i][j]` 的语义相应变成「到 `(i,j)` 的所有路径中，最小的那个『最大高度差』」。
>
> **另一条路：二分答案 + BFS**。二分「允许的最大高度差」`mid`，只走差值 $\le mid$ 的边，check 能否连通。这就是 [[3.1 二分答案]] 的标准套路，$O(mn\log C)$。两种解法都该会——面试官常问「还有别的做法吗」。

### 变体三：Floyd（1334. 阈值距离内邻居最少的城市）

![](assets/9.3%20Floyd%20为什么k在最外层.svg)

> [!tip]- 核心思路：Floyd 是一个「逐步放开中转点」的 DP
>
> 定义 `f[k][i][j]` = **只允许把 $\{0, 1, \ldots, k\}$ 当中转点**时，`i` 到 `j` 的最短距离。转移就是「第 `k` 个点用不用」：
>
> $$f[k][i][j] = \min\big(f[k-1][i][j],\ f[k-1][i][k] + f[k-1][k][j]\big)$$
>
> 两段子路径都不经过 `k` 本身（最短路不会重复经过同一点），所以可以安全地查上一层。
>
> **`k` 必须在最外层**，因为它是 DP 的**阶段**。挪到内层就等于「在别的 `(i,j)` 对还停在早期阶段时，就拿它们的值去更新」，得到偏大的结果。这和 [[7.2 背包以及完全背包]] 里「物品维必须是外层循环」是同一条原则。
>
> **`k` 这一维可以滚动掉**：更新 `f[i][k]` 时用到 `f[i][k] + f[k][k]`，而 `f[k][k] = 0`，所以本层值和上层值相等，就地覆盖是安全的。这就是那个著名的三重循环。

> [!success]- 代码实现
>
> ```python
> class Solution:
>     def findTheCity(self, n: int, edges: List[List[int]], distanceThreshold: int) -> int:
>         f = [[inf] * n for _ in range(n)]
>         for i in range(n):
>             f[i][i] = 0
>         for u, v, w in edges:
>             f[u][v] = f[v][u] = min(f[u][v], w)  # min 防重边
>
>         for k in range(n):                       # 阶段：必须最外层
>             for i in range(n):
>                 for j in range(n):
>                     f[i][j] = min(f[i][j], f[i][k] + f[k][j])
>
>         ans, best = 0, n + 1
>         for i in range(n):
>             cnt = sum(f[i][j] <= distanceThreshold for j in range(n) if j != i)
>             if cnt <= best:                      # 并列时取编号最大的
>                 best, ans = cnt, i
>         return ans
> ```
>
> - 初始化三件事：对角线置 0、重边取 `min`、无边为 `inf`。漏掉任何一件都会错。
> - 无向图要 `f[u][v]` 和 `f[v][u]` 同时赋值。
> - $O(n^3)$，$n \le 100 \sim 400$ 才用得起；再大就对每个点跑一次 Dijkstra。

### 变体四：边权只有 0 和 1 —— 0-1 BFS

> [!tip]- 用双端队列代替堆，$O(E\log V)$ 降回 $O(V+E)$
>
> 当边权只有 0 和 1 时，不需要堆：走 0 边就 `appendleft`（不增加距离，优先处理），走 1 边就 `append`。双端队列里的距离天然保持单调，效果等价于 Dijkstra 但没有 $\log$。
>
> 典型题：1368 使网格图至少有一条有效路径的最小代价（顺着箭头走代价 0，改方向代价 1）。
>
> 这也说明 BFS / 0-1 BFS / Dijkstra 是同一条线上的三级台阶：**队列 → 双端队列 → 优先队列**，容器的选择由边权的种类决定。

## 易错点

> [!warning]- 易错点
>
> **1. 有负权边还用 Dijkstra**
> 结果偏大且不报错。必须能当场说出反例：`0→1 (2)`、`0→2 (5)`、`2→1 (−4)`。
>
> **2. 忘记 `if d > dis[x]: continue`**
> 不会得到错误答案（松弛条件会挡住），但堆里的过期项会被反复展开，复杂度退化，大数据超时。
>
> **3. 堆里存 `(点, 距离)`**
> 顺序反了，Python 会按点编号排序，整个算法失效。必须 `(距离, 点)`。
>
> **4. Floyd 把 `k` 放在内层**
> 最常见的 Floyd 错误。`k` 是阶段维，必须最外层。
>
> **5. Floyd 忘记初始化对角线**
> `f[i][i]` 不置 0，转移里 `f[i][k] + f[k][j]` 全是 `inf`，结果全错。
>
> **6. Floyd 处理重边直接赋值**
> `f[u][v] = w` 会让后出现的重边覆盖掉更短的那条。要写 `min`。
>
> **7. 用 `dis` 数组当访问标记**
> Dijkstra 不需要额外的 `visited`——「已确定」这件事由 `if d > dis[x]` 隐式表达。硬加一个 `visited` 反而容易写出「入堆时标记」这种错误（应该出堆时才算确定）。
>
> **8. `inf` 参与加法溢出**
> Python 的 `math.inf` 相加仍是 `inf`，安全；C++ 里用 `INT_MAX` 相加会溢出成负数，要用 `0x3f3f3f3f`。跨语言面试时值得提一句。

## 复杂度

> [!summary]- 复杂度
>
> | 算法 | 时间 | 空间 | 说明 |
> | --- | --- | --- | --- |
> | BFS | $O(V+E)$ | $O(V)$ | 边权全 1 |
> | 0-1 BFS | $O(V+E)$ | $O(V)$ | 边权只有 0/1，双端队列 |
> | Dijkstra 朴素 | $O(V^2)$ | $O(V)$ | 稠密图更优 |
> | Dijkstra 堆优化 | $O(E\log V)$ | $O(V+E)$ | 稀疏图更优；懒删除下堆里最多 $E$ 个条目 |
> | Bellman-Ford | $O(VE)$ | $O(V)$ | 能处理负权、判负环 |
> | Floyd | $O(V^3)$ | $O(V^2)$ | 多源；滚动掉 `k` 维后空间是 $O(V^2)$ |
>
> **选型的量纲感**：$n \le 400$ 且要全源 $\to$ Floyd；单源且边权非负 $\to$ Dijkstra；点多边少优先堆优化。

## 一句话总结

最短路的四件套只差一个「容器」：边权全 1 用**队列**（BFS），边权 0/1 用**双端队列**，边权非负用**优先队列**（Dijkstra）；而 Floyd 根本不是搜索，是一个以「允许借道哪些点」为阶段的 DP，所以 `k` 必须在最外层。

## 模板归纳

**触发信号**：题面出现「最小代价 / 最短时间 / 最少花费」+ 图或网格 + **边的代价不全相同**。

**四问选型**：

1. **边权都是 1 吗？** 是 $\to$ 直接 BFS，别上 Dijkstra。
2. **有负权吗？** 有 $\to$ Bellman-Ford；没有 $\to$ Dijkstra。
3. **要所有点对吗？** 要且 $n$ 很小 $\to$ Floyd。
4. **边权只有 0 和 1 吗？** 是 $\to$ 双端队列，省掉 $\log$。

**Dijkstra 手写四步**（顺序固定，不会漏）：

1. 建邻接表 `g[u] = [(v, w)]`。
2. `dis = [inf] * n`，`dis[start] = 0`，`h = [(0, start)]`。
3. 循环：`d, x = heappop(h)` → **先写 `if d > dis[x]: continue`** → 遍历邻居松弛，成功才入堆。
4. 读答案；不可达是 `inf`，记得转成题目要求的 `-1`。

**Floyd 手写三步**：对角线置 0 → 重边取 `min` → 三重循环 `k` 在最外层。
